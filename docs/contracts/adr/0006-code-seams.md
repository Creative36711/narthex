# ADR 0006. Код в объявленных швах

Дата: 2026-10-23
Статус: принято

## Контекст

Готовая система (редактор, формы, валидаторы) ускоряет работу, но ограничивает
свободу. Мастеру нужно уметь сделать то, чего нет в конструкторе. Полное
отключение движка и «пиши что хочешь» звучит как решение, но уничтожает три
вещи, ради которых существует платформа: формат проекта, перенос сохранений и
машинную проверку. Проект с произвольным кодом перестаёт быть проверяемым, а
значит перестаёт отличаться от обычного игрового движка.

## Решение

Свобода — три уровня, каждый следующий снимает часть гарантий:

1. **Данные** — формы и реестры.
2. **Выражения** — условия, эффекты, формулы (Turing-неполный DSL).
3. **Код** — только в **объявленных швах**, которые пак описывает в
   `provides.seams`.

Шов имеет `id`, вид и сигнатуру. Видов два:

| Вид | Что делает | Проверяется | Меняет состояние |
|---|---|---|---|
| `sim` | логика: ход, урон, торговля | headless и `check` | да, через `EngineCtx` |
| `view` | рисование, звук, эффекты | кадры, не headless | нет |

Правила:

- **Режим по возможности**, а не на проект: `core`, `code`, `off`.
  `off` сохраняет данные и выключает поведение; включение обратно не требует
  миграции.
- **Редактор не умирает.** При `code`/`off` пропадают формы подсистемы,
  остаются дерево файлов, Monaco, запуск и `check`.
- **Песочница.** Отдельный воркер, явные права (`render`, `audio`, `input`,
  `state`), сети нет по умолчанию.
- **Сейвы.** Код может менять форму сохранения только вместе с миграцией,
  объявленной проектом.
- **Пометка.** Проект с кодом получает бейдж в мастерской.

## Последствия

**Положительные.** Автор получает свободу, не теряя проект; `check` продолжает
работать для `sim`; мастерская может честно предупредить игрока; студия
остаётся одной.

**Отрицательные.** Появляется вторая категория проектов — с кодом, который
нельзя проверить полностью. Для `view` вердикт даёт человек или визуальный
аудитор. Это записано в `vision.md` как цена свободы, а не скрыто.

## Что стало невозможным

- Подключить код к шву, которого пак не объявил.
- Изменить состояние из `view`-кода.
- Выпустить проект с кодом, меняющим сейв, без миграции.
- Ходить в сеть из кода по умолчанию.
- Скрыть от игрока, что в проекте есть код.
