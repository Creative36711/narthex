# ADR 0014. Realtime-проект как внутренняя fixture cf-play

- Статус: принят.
- Решение: хранить проект `realtime-wall-zone` в `_tools/projects/realtime-wall/`; цикл объявлен в его `project.json` и не оформляется как отдельный pack.
- Проверка `cf-play cycles` объединяет его с `public/campaigns/ash-of-caerden` через общий загрузчик и общий цикл `Executor.step`; публичный реестр кампаний не меняется.

Проект остаётся исполняемой офлайн-fixture для проверки ввода, блокировки стены и одноразового триггера зоны. Он не устанавливает `endless-2d`, не меняет реестр packs или зрелость Phase 4 и не попадает в каталог игрока. Если позже появится отдельный игровой realtime-пак, fixture можно перенести без изменения кампаний narrative.
