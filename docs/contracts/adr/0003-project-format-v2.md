# ADR 0003. Формат проекта v2

Дата: 2026-10-22
Статус: принято (draft до первого стороннего пака)

## Контекст

`campaign.json` описывает кампанию одного вида. Платформе нужны тип проекта,
список включённых возможностей и требования к движку — иначе студия не знает,
какие панели открыть, а движок не знает, отказаться ему или догадаться.

При этом ломать существующие пакеты нельзя: пять кампаний и внешние проекты
обязаны открываться без ручной правки.

## Решение

1. Новый файл `project.json` в корне проекта: `format: 2`, `kind`, `caps`,
   `engine`, `entry`.
2. Старый пакет без `project.json` читается как `format: 1, kind: "narrative"`,
   а `caps` выводятся из `campaign.features`.
3. Миграция не перезаписывает `campaign.json`: `project.json` появляется при
   первом сохранении из студии.
4. `kind` — из закрытого списка `caps.json` (пять направлений). Сторонние типы
   проектов — только в v3 и только через пак, объявивший `provides.kind`.
5. Смешение `turn` и `realtime` в одном проекте запрещено.

Полная спецификация — `../format-v2.md`, схема — `../project.schema.json`.

## Почему отдельный файл, а не поля внутри `campaign.json`

- `campaign.json` — это контент автора, `project.json` — метаданные сборки.
  Держать их вместе значит, что студия переписывает авторский файл при каждом
  сохранении и появляется конфликт в git.
- Формат 1 остаётся нетронутым: старый файл читается как есть, без «адаптера
  поверх адаптера».
- Внешнему инструменту (мастерская, `check`, кит) достаточно одного маленького
  файла, чтобы понять проект, не разбирая контент.

## Последствия

- Два файла в корне: `project.json` + `manifest.json`. Это дешевле, чем один
  файл, который одновременно описывает и мир, и сборку.
- `id` проекта дублируется в `campaign.json` (`campaign.id`) на время
  переходного периода. При расхождении прав `project.json`, а расхождение
  считается дефектом и логируется.
- Мастерская публикует `project.json` + `manifest.json` + хэши. Контент лежит
  у автора.

## Что стало невозможным

Нельзя сделать проект «во всех направлениях сразу». Нельзя также добавить
поле без схемы: `additionalProperties: false` отклоняет опечатки, а расширения
живут только в `x-*`.
