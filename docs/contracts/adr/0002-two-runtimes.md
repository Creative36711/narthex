# ADR 0002. Два исполнителя вместо пяти движков

Дата: 2026-10-22
Статус: принято

## Контекст

Пять направлений платформы выглядят как пять независимых движков:

1. Spatial Action — 3D, физика, анимация.
2. Grid & Strategy — сетка, A\*, экономика.
3. State-Machine & UI — пошаговый автомат, карты, интерфейсы.
4. Narrative & Branching — сцены, диалоги, флаги.
5. Endless & Physics 2D — непрерывное время, 2D-физика.

Разработка пяти движков силами ИИ-команды — это гарантированный способ не
довести ни один. Нужен разрез, при котором направление добавляется, не
умножая ядро.

## Решение

Все направления сводятся к **двум исполнителям** и набору **паков**:

- **turn** — пошаговое состояние: narrative, state-machine, grid.
- **realtime** — непрерывный цикл: 2D-физика, позже 3D.

Направление = пак: схема данных, панели студии, статические валидаторы,
динамические пробы. Пак не добавляет третий исполнитель.

Порядок работ определяется стоимостью, а не порядком в таблице:
narrative → state-ui → grid-strategy → endless-2d → spatial-3d.

## Почему три направления — один исполнитель

| Требование | narrative | state-ui | grid |
|---|---|---|---|
| Состояние пошаговое | да | да | да |
| Детерминизм от seed | да | да | да |
| Ввод по событиям, не по кадрам | да | да | да |
| Нужен поиск пути | нет | нет | да |
| Нужен игровой автомат | неявно | явно | явно |

Различия — в модели состояния и представлении, а не в способе исполнения.
Поэтому один цикл, три директора поведения.

## Последствия

**Положительные.** Два рантайма вместо пяти. Каждый новый пак проверяется
одним и тем же `check`. Команда агентов делится по зонам, а не по жанрам.

**Отрицательные и как их держим под контролем.**

- Три направления делят один цикл → изменения в цикле бьют по всем сразу.
  Ответ: ядро меняется только через ADR, регрессия — на всех паках сразу.
- Смешение `turn` и `realtime` в одном проекте невозможно. Ответ: честная
  ошибка формата, гибрид — отдельная возможность с контрактом, а не поблажка.
- 3D откладывается. Ответ: это решение, а не забывчивость; критерий входа в
  фазу 8 — два работающих пака и зелёные фикстуры.

## Что стало невозможным

Нельзя добавить направление, которое требует третий цикл (например,
пошаговый с физикой в реальном времени), без нового ADR. Это осознанно:
третий рантайм — это третья команда и третья регрессия, а не «ещё один пак».
