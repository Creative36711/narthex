# ADR 0001. Имя платформы: Narthex

Дата: 2026-10-22
Статус: **выполнено** (переименование завершено 2026-10-22, см. «Ревизию»)
Исходный статус: принято как рабочее имя

## Контекст

Проект вырос из движка визуальных новелл Chronicle Forge до платформы под пять
направлений. Старое имя описывает один жанр и мешает разговору о платформе:
«Chronicle Forge» — это уже и репозиторий, и движок, и формат, и сообщество.

Из десяти предложенных вариантов выбран **Narthex** — притвор базилики, узкий
вход, ведущий внутрь. Смысл: разные миры входят в одну платформу через общий
порог. Слово редкое, короткое, не содержит мёртвых приставок вроде -verse и
-craft.

## Проверка конфликтов (2026-10-22)

| Найдено | Риск | Вывод |
|---|---|---|
| `github.com/swimmingoncode/narthex` — «spec-driven development for agentic teams», codename с 2026-10-17 | средний: та же область (ИИ-агенты), но это инструмент планирования, а не игровая платформа | не блокирует рабочее имя, блокирует публичный запуск без проверки |
| `narthexwargaming.co.uk` — розничный магазин настольных игр | низкий: другая отрасль, другое написание в домене | не блокирует |
| Торговые марки в EU/DE | не проверено из песочницы | обязательная проверка до публичного релиза |

## Решение

Narthex — имя платформы **и** кодовой базы. Отдельного «кодового имени»
больше нет.

## Ревизия 2026-10-22: переименование выполнено

Первоначальная редакция этого ADR оставляла `chronicle-forge` как кодовое имя
до фазы 4. Решение отменено: ребрендинг делается один раз, пока нет ни одного
игрока и ни одной установки.

Что переименовано:

| Слой | Было | Стало |
|---|---|---|
| репозиторий | `Creative36711/chronicle-forge` | `Creative36711/narthex` |
| npm-пакет, крейт | `chronicle-forge` | `narthex` |
| приложение Tauri | `Chronicle Forge`, `app.chronicleforge.desktop` | `Narthex`, `app.narthex.desktop` |
| ключи `localStorage` | `chronicle-forge:save:*`, `:meta:*`, `:settings`, `:map-labels`, `:playtest-notes*` | `narthex:*` |
| форматы обмена | `chronicle-compat/1`, `chronicle-inventory/1` | `narthex-compat/1`, `narthex-inventory/1` |
| пакет кампании | `.chronicle` | `.narthex` |
| файл сохранения | `.cfsave` | `.nxsave` |
| подпись профиля темы | «Chronicle Forge» (id `forge`) | «Narthex» (id `forge`) |
| схема | `https://chronicle-forge.local/…` | `https://narthex.local/…` |

Миграция совместимости **не писалась намеренно**: на момент переименования
игроков нет, установок нет, `compat.json` не существует ни в одной кампании.
Единственное исключение — атрибуты `accept` в диалогах выбора файла: там
старое расширение оставлено рядом с новым, потому что это фильтр в разметке,
а не код.

Что **не** переименовано и почему:

- `package_format`, `format`, `SAVE_VERSION` — номера версий, не бренд;
- `panel:chronicle`, категория кодекса `'chronicles'` — игровое понятие
  «Хроника», а не имя продукта;
- id визуального профиля `forge` — лежит в данных существующих кампаний
  (`meta.theme.profile`); меняется только отображаемая подпись;
- `__chronicle_ai__` — отложено вместе с переносом кита в репозитории кампаний
  (в коде есть проверка по литералу, слепая замена ломает исключение папки при
  импорте).

## Последствия

- Старые ссылки на репозиторий работают через редирект GitHub.
- Пользователи старых сборок при обновлении потеряли бы настройки и сейвы —
  таких пользователей нет, поэтому миграция не предусмотрена. Как только
  появится первая установка, любое переименование идентификаторов потребует
  миграции.
- `Задание для ИИ` теперь учит агента расширению `.narthex`; кит в старых
  репозиториях кампаний продолжит работать, потому что движок читает содержимое
  zip, а не имя файла.

## Что стало невозможным

Нельзя использовать «Narthex» как имя функции, пака или внутреннего модуля —
иначе появится второй смысл и его придётся объяснять в каждом разговоре. То же
касается слова «Chronicle» в брендовом смысле: оно осталось только как название
внутриигровой панели.
