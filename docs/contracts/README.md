# Контракты платформы

Каталог фиксирует то, что нельзя менять по ходу дела: формат проекта, манифест
пака и реестр возможностей. Здесь нет описания «как устроен код» — только
договоры, на которые этот код опирается.

## Правило: контракт — это код

Любой контракт существует в трёх видах, и все три обязаны совпадать:

1. **Текст** — что правило значит и почему оно такое.
2. **Схема** — машинная проверка формы.
3. **Проверка** — `npm run check:contracts`: схема компилируется, примеры
   валидируются, семантика (kind→caps, рантаймы, совпадение пака с реестром)
   проверяется кодом, негативные примеры обязаны падать.

Если правило нельзя выразить в этих трёх видах, это не контракт, а пожелание.
Пожелания живут в `docs/platform.md`, а не здесь.

## Как менять контракт

1. **Предложение.** ADR в `adr/` по шаблону: контекст → решение → последствия
   → что стало невозможным.
2. **Схема и пример.** Правка `*.schema.json` и хотя бы один пример,
   показывающий новое поле в работе.
3. **Проверка.** Новое правило добавляется в `scripts/contracts-check.mts`.
   Если правило нельзя проверить — пункт 1 не принят.
4. **Совместимость.** Если меняется смысл существующего поля — это новая
   версия формата, а не правка текущей. Читатели обязаны понимать предыдущую.

## Версии

- `format` в `project.json` — версия формата проекта, целое число.
- `version` в манифесте пака — semver; ломающее изменение поднимает мажор.
- `version` в `caps.json` — целое; увеличивается при добавлении, переименовании
  или смене статуса возможности.

Правило совместимости: **новый движок читает старые проекты всегда**. Обратное
не гарантируется, и это нормально: старый движок не обязан знать о новых полях,
но обязан честно сказать «нужна версия не ниже X», а не падать.

## Что здесь намеренно не описано

- Внутренние типы TypeScript (`src/shared/types.ts`) — это реализация, она
  может меняться, пока контракт соблюдается.
- Сетевой протокол и мастерская — до фазы 10 у них нет обязательств.
- Мультиплеер — зарезервированные возможности есть в реестре, контракта нет.
