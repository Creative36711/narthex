# NAR-2.3 — настоящие данные `narrative` через хост пака

## Исходная карточка

- **неясно** — на момент исходной карточки в `main` ещё не было `public/campaigns/ash-of-caerden-adventure`, а собранный `public/ai/cf-play.mjs` не имел команды `explain`; оба пути находились вне Scope, при этом ядро и формат сейва менять было запрещено.
- **решил** — эталонная кампания целиком и без изменений контента помещена в `packs/narrative/data/ash-of-caerden/` и дополнена `project.json` формата 2; чистые `sim`/`view` подключаются к `PackHost` через манифест, а проба прогоняет реальный маршрут, 20/20 одинаковых seed и тот же `cf-play` на данных пака. `cf-play explain --catalogue` добавлен в исходный CLI и читает только `packs/registry.json` + `pack.json`; собранный бандл в исходной карточке не перезаписывался.
- **откат** — удалить данные, хуки и пробу пака, команду `probe:narrative-pack`, вернуть прежние манифест/схемы и два файла исходного CLI; миграций и изменений существующих сейвов нет, `saves` остался `narrative` v3.

Исходное допущение: буквальная проверка `ash-of-caerden-adventure` была заменена проверкой самодостаточной копии эталона внутри пака. Это ограничение относится только к исходной карточке и закрыто ниже в NAR-2.3-Б. Эталон §2.1 не изменён: 10 сцен, 8 локаций, 6 диалогов, 21 узел, 0 errors / 8 warnings, 5 смертей, покрытие 6/10.

## NAR-2.3-Б — проект по пути оракула

- **неясно** — нужен был авторски открываемый проект именно в `public/campaigns/ash-of-caerden-adventure`, а не только pack-data probe; при этом публикация могла быть ссылкой или копией, а `project.json` намеренно не входит в сравнение content-файлов publisher-а. Нужно было выбрать обратимый вариант без знания core о кампании.
- **решил** — использована уже существующая в `main` запись `packs/publications.json` для alias `ash-of-caerden-adventure`: `npm run publish:campaigns` публикует 99 content-файлов из `packs/narrative/data/ash-of-caerden`, а в public-проект отдельно добавлен `project.json` формата 2 с `kind: "narrative"`, capabilities из манифеста и прежним стабильным `id: "ash-of-caerden"`. Это публикуемый alias одного проекта, а не вторая версия контента и не новый pack-specific код. `explain` и его bundle уже присутствуют в `main` после PR #47, поэтому исходники и bundle в этой карточке не менялись.
- **откат** — удалить только `public/campaigns/ash-of-caerden-adventure/` и этот отчёт; пак, существующий mapping, `src/`, формат сейвов и остальные публичные кампании не затрагиваются. При повторной публикации каталог восстанавливается командой `npm run publish:campaigns` с последующим восстановлением его `project.json` из pack-data.

Допущение NAR-2.3-Б: одинаковый `project.id` у alias и pack-data сохранён намеренно — стабильный id не переименовывается, а различающийся путь является публикацией, не новой кампанией. Проверка `check:campaigns` сверяет 99 content-файлов (2 из 2 публикаций); литеральный `cf-play check` отдельно подтверждает наличие и разрешение public `project.json` через `narrative`.
