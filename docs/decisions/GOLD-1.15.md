# GOLD-1.15 — one-hour golden playthrough from fresh game to first clue

Статус: accepted
Дата: 2026-10-30
Дата решения: 2026-10-30
Решил: принятие карточки GOLD-1.15
Основание: [Замечание Мастера 1 при возврате миссии 2026-10-30, §1.4/1.7 — GOLD-1.15](https://app.notion.com/p/GOLD-1-15-1-4-1-7-60-playthrough-golden-CI-4096f0cf570581c1abdeca8f2d524121)
Заменяет: [GOLD-1.11](./GOLD-1.11.md)

## Контекст

Часовой soak GOLD-1.11 запускался отдельной командой и не был обязательной частью
общего `npm run playthrough:golden` и push CI. Его активная временная шкала
начиналась уже в машинном зале после части маршрута; на checkpoint 0 первая улика
кампании `clue_glove` ещё не была получена. Прежний довод GOLD-1.11 «часовой soak
не в CI» снят замечанием Мастера 1 и больше не является допустимым основанием
держать soak отдельно.

## Решение

Сохранить существующий `npm run golden:soak` и его реальное браузерное исполнение.
Единая команда `npm run playthrough:golden` запускает действующие проверки
кампании/предупреждений, а затем вызывает `npm run golden:soak`; код возврата
общей команды равен 0 только если прошли обе части. Soak включает состояние
свежей игры в начало часового интервала, проходит маршрут кампании и отмечает
реальную первую улику `clue_glove` в полном JSONL timeline. После достижения
улики тот же браузер продолжает часовой прогон; время не перематывается и не
подменяется моками.

Порог активной игры остаётся 3600 секунд; используются реальные пятиминутные
контрольные точки (не менее 12), не более 60 секунд между активными UI/game actions,
ноль `pageerror`, ноль пустых фонов и фактически воспроизведённый звук меню.
Отчёт отдельно сообщает `durationSeconds`, активную длительность и количество
checkpoint'ов. Лог GOLD-1.15 содержит стартовый checkpoint, событие первой улики,
полную пятиминутную временную шкалу и итоговые числа.

Workflow `golden-playthrough` выполняет ту же единую команду без условного
пропуска на `push` в `main`. Timeout job — 90 минут; timeout шага общей команды —
82 минуты. GOLD-1.15 report/log загружаются отдельным CI artifact.

GOLD-1.11 сохраняет только однострочный указатель на это решение;
историческое обоснование не переписывается и не применяется после этой записи.

## Границы и допущение

- `.golden/karkas` и `campaign-1` только читаются; `.golden/**` не коммитится.
  `src/core/**`, `src/player/**`, `packs/**` и `docs/contracts/**` не меняются.
- **Допущение о стартовом состоянии:** `.golden/manifest.json` pins a fresh game
  whose observed `scene_gate_hall` state is HUD `День 1, 07:00` with opening flags
  `case_opened` and `gate_intro_done`; the clue flags are empty. Это видно в
  сохранённом GOLD-1.11 run log. В рамках этой карточки старт фиксируется
  буквально, а не приводится к указанным в карточке HUD `08:00` и пустому объекту
  flags искусственным сбросом: никакие campaign/core данные и игровое время не
  меняются. Это сохраняет реальный старт, но отличается от этих двух ожидаемых
  значений карточки.
- **Допущение о недостающей записи:** `docs/decisions/GOLD-1.11.md` отсутствует на
  `main`; создан только запрошенный однострочный указатель, без реконструкции
  несуществующего в checkout текста ADR.

неясно: карточка задаёт HUD `08:00` и пустые flags на старте, но pinned fresh-run log показывает HUD `07:00` и два неизменяемых opening-флага; `docs/decisions/GOLD-1.11.md` на `main` отсутствует.
решил: сохранить наблюдаемое начало игры и проверять пустые clue flags, не редактируя campaign/core и не сдвигая время; создать GOLD-1.11 только как однострочный supersession pointer.
откат: если источник campaign будет отдельно обновлён до указанного старта, восстановить точное assertion по нему; если исходный ADR GOLD-1.11 будет предоставлен, заменить pointer одной строкой в нём, не меняя его обоснование.

## Откат

При отдельном решении вернуть soak к прежней временной точке можно откатить только
GOLD-1.15 orchestration/start-checkpoint changes и удалить pointer, если оригинал
GOLD-1.11 будет восстановлен. Не менять сохранённые oracle thresholds, campaign,
core, player или пакеты в рамках такого отката.
