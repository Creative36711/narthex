# GOLD-1.14 — strict warning verdict for `cf-play check`

Статус: accepted
Дата: 2026-10-30
Дата решения: 2026-10-30
Решил: принятие карточки GOLD-1.14
Основание: GOLD-1.14 §1.3/1.7.

## Контекст

`cf-play check` уже включал статические предупреждения в отчёт, но выставлял
`verdict: ok` и код возврата `0`, если не было ошибок и провалов прогона.
Получалось, что проверка кампании могла успешно завершиться с известными
предупреждениями. Это расходится с требованием считать предупреждение дефектом
для этой команды.

## Решение

Любое предупреждение `analyzeCampaign()` делает `cf-play check` неуспешным:
вердикт — `failed`, код возврата — `1`, в диагностике есть точная подпись
`warning не допускается`. Счётчики ошибок и предупреждений и сами сообщения
сохраняются; фильтров, флагов подавления и переменных окружения для обхода
правила нет.

Положительная проверка закреплена на импортированной `.golden/karkas`: ноль
ошибок, ноль предупреждений, `verdict: ok`, rc=0. Отрицательная проверка
использует `_tools/fixtures/cf-play-warning/`: одно статическое предупреждение,
ноль ошибок, `verdict: failed`, rc=1. Один `npm run playthrough:golden` запускает
оба доказательства, а workflow дополнительно вызывает `npm run cf-play:negative`
отдельным шагом.

`public/ai/cf-play.mjs` — CLI, который включается в распакованный AI kit. Поэтому
он пересобран из локального источника `scripts/playkit/cli.mts`; golden и
negative checks проверяют поведение как исходника, так и поставляемого bundle.

## Границы и допущение

- Изменён только код `cf-play`, harness/CI, минимальная fixture и связанные
  отчёты. `campaign-1`, `.golden/karkas`, `src/core/**` и `src/player/**` не
  редактируются; `.golden/**` не коммитится.
- **Допущение:** warning-only fixture — один доступный стартовый dead-end scene
  без дорог, а минимальный FMV JSON оставляет штатный narrative-pack entry event
  рабочим. Такой fixture даёт ровно одно стабильное предупреждение, не меняя
  проверяемую кампанию.

## Откат

Если принятое правило будет отменено отдельной карточкой, вернуть только
warning-gate в `scripts/playkit/cli.mts`, пересобрать `public/ai/cf-play.mjs` и
обновить негативный контракт вместе с тестом. Не ослаблять другие проверки и не
изменять импортированную кампанию.
