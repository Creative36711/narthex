неясно / Как сохранить строгие проверки, не редактируя защищённые campaign data? Исторический Ash имеет единственное расхождение title/author, Ash и FMV fixture содержат два baseline-наблюдения, а 33 уже существующих файла дают прежние брендовые совпадения; FMV-расширение также не принадлежит legacy-аудитору.
решил / Разрешить только совпадающие с `df93c7be3d455e917f00a1d5fa0506ef4a434350` хэши: для campaign gates — полный tree/index и точные Ash metadata blobs, для brand gate — 33 file hashes; любой новый путь или изменённый байт снова проваливает проверку. FMV валидировать через `auditCampaignFmv()` и передавать legacy-аудитору только `withoutFmvExtension()`. `npm run build` ограничить `tsc -b && vite build`, сохранив отдельную цель AI-bundle; это удерживает закреплённый SHA. Никаких изменений кампаний, порогов, трёх Ash warnings или §3 oracle.
откат / Отменить только изменения скриптов, package scripts и документов STAB-1.21; восстановить исполняемые gates и точные baseline-хэши. Защищённые campaign data, packs, golden-пути, thresholds и oracle не откатывать и не изменять.
