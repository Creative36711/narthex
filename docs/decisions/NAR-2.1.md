# NAR-2.1 — registry-backed capability packs

- **Неясно:** реестр может быть отдельным файлом или выводиться сканированием каталогов; манифесты описывают панели, но не задают реализацию React-компонентов.
- **Решил:** `packs/registry.json` — авторитетный список данных; каталог и `pack.json` каждого пакета должны быть зарегистрированы, без перечисления ID в коде. Core, Studio и `check:packs` используют один resolver; Studio показывает данные четырёх частей манифеста как каталог, не исполняя произвольный код из паков. `caps` проверяются один-к-одному по runtime-реестру.
- **Откат:** удалить `packs/`, pack resolver/catalog UI, schema-копию, `check:packs` и его npm-вызов; вернуть `check:contracts` к прежней команде. Campaign oracle и существующие checks остаются без изменений.
