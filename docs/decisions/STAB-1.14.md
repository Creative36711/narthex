# STAB-1.14 scope decision

- **Ambiguity:** `scripts/mission-smokes/**` does not exist; the actual runner is `scripts/mission-smokes.mts`, while probes reading text from either target module are spread across `scripts/*`.
- **Decision:** Treat every existing probe that reads source text specifically from `CampaignEditor.tsx` or `EditorApp.tsx` as in scope, regardless of its `scripts/` subdirectory. Replace only those path-bound fragment checks with the owner module's public API/import/re-export/call, preserving each check's meaning and accessibility. Keep unrelated checks, path-only existence checks, and `check-module-size.mts` hash pins unchanged. Add no probe or source files; keep probe count unchanged.
- **Focused ambiguity:** `tz7-slots-smoke.mts` asserts campaign-owned equipment slots (`meta.equipment_slots`), while `slotTypesFor(EditorStore)` serves the separate scene-slot registry (`meta.slot_types`). The probe now checks equipment slots through `equipmentSlots(editorStore.meta)` and separately verifies `slotTypesFor` has no defaults for an empty campaign registry. This keeps the original equipment-registry assertion semantically exact while exercising the requested owner API; the two assertions can be split/reversed independently without changing production code.
- **Inline-owner ambiguity:** several retained labels/widgets are still inline within `CampaignEditor` or `EditorApp`, whose public boundary is the component itself rather than a separately exported handler. Where the child is public, probes render its markup; elsewhere they import/re-export the owner and pair it with public menu/store/audit APIs or campaign data. React server rendering cannot exercise pointer/keyboard/localStorage interactions, so those private handlers are checked through owner accessibility plus related public behavior rather than source-text inspection; this is reversible if those handlers gain explicit public APIs later. No repository-wide replacement scan was added; unrelated file/path checks remain unchanged.
- **Ownership correction:** `feedback8-A` A5 inspects `WorldEditor`, not either target owner; it remains unchanged. Only CampaignEditor-owned A3/A7 checks were migrated.
- **Reversal:** Revert the affected probe/runner edits and remove this decision record. No changes are permitted under `src/**`, `public/**`, `packs/**`, the protected golden/contracts paths, or `package.json`.
