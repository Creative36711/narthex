# STAB-1.17 — решение по §4 и остаточным красным воротам

Дата: 2026-10-31
Статус: proposed

неясно: §4 требует итог по всем 21 воротам и называет check:mission обязательным успешным gate, но он агрегирует RC 1 из чужих карточек и защищённых путей; без изменения scope или oracle получить RC 0 невозможно, поэтому каждый остаток нужно явно объяснить владельцем.
решил: Адаптировать ScriptCat к текущему `narthex.user.js` и Gateway 1.5, сохранить все 71 проверки и отрицательные сценарии, привязать остаток к STAB-1.18/1.19/1.21 либо указать точный выход за Scope, изолировать build и check:mission, затем выполнить squash-merge PR #182 по карточке, даже если назначенные другим владельцам ворота остаются красными.
откат: Не трогать защищённые пути, пороги, исключения и oracles; если решение отменено, отдельным revert вернуть только изменения STAB-1.17 и оставить исходные проверки нетронутыми.
