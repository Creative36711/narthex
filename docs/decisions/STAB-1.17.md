# STAB-1.17 — решение по §4 и остаточным красным воротам

Статус: accepted
Дата решения: 2026-10-31

Решил: Сохранить все 71 проверки и отрицательные сценарии ScriptCat, исправлять только работу в назначенном scope, а остатки привязывать к владельцу и карточке; PR #182 принят squash-merge после выполнения своего scope.
неясно: RC 1 у `check:mission` на промежуточном этапе объяснялся незавершённой работой и пробами, назначенными другим карточкам (STAB-1.18/1.19/1.21), а не невозможностью получить RC 0 без изменения оракула.
откат: Этот ADR не разрешает менять смысл старого оракула: такие изменения допустимы только в пределах §2.5; при отмене решения отдельным revert вернуть только изменения STAB-1.17, не трогая проверки и их прежний смысл.
