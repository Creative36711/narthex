# STAB-1.23 — reproducible audit bundle and clean checkout

**Статус:** accepted
**Дата решения:** 2026-10-31

- **Неясно:** оставить ли historical pin на commit `0a5abca` источником истины для `check:audit-bundle`, хотя карточка требует сверки с текущим исходником.
- **Решил:** считать единственным источником истины текущий `scripts/campaign-audit.mts`; общий builder формирует и опубликованный, и проверочный бандл, а checker требует два идентичных результата и побайтовое совпадение с `public/ai/campaign-audit.mjs`. Пересборка добавила в bundle строки, уже входящие в legacy-код зависимостей; поэтому pin brand guard обновляется только на точный SHA `0298805c8c6c038155500fc4dd7b67fc0f0f51c5ead761dea32eb476ee2ca9b8`. Smoke проверяет, что изменённые байты и новый путь по-прежнему отклоняются.
- **Откат:** вернуть прежний checker/build script, прежний точный pin brand guard и исходный audit bundle из родительского коммита; `dist-ai/` оставить вне checkout через временные выходные каталоги проверок.
