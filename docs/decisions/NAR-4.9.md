# NAR-4.9 · Закрытие фазы 3

Статус: accepted
Дата: 2026-10-27
Дата решения: 2026-10-27
Основание: оракул фазы 3 из [ТЗ NAR-4](../agents/tz-nar-4.md) и неизменённый раздел [«Фаза 3»](../phases.md).

## Решение

**Фаза 3 закрыта 2026-10-27.** Все критерии «Готово, когда» подтверждены:
парные проекты `turn`/`realtime` дважды проходят `cf-play cycles` с побайтно
одинаковыми выводами; parity — 10/10; общий `cf-play` не ветвится по рантайму;
пошаговые эталоны и браузерный экзамен проходят; медиана/p95 кадра записаны с
машиной; локальный lint завершился с 0 ошибками. Также `npm run check:mission`
проверяет оба рантайма и завершился rc=0. Вся таблица фактических источников,
числа и оба вывода `cf-play cycles` — в
[отчёте NAR-4.9](../../_tools/reports/NAR-4.9.md).

Источники CI привязаны к командам, которые действительно есть в workflow:
[visual run #40537871691](https://github.com/Creative36711/narthex/actions/runs/40537871691)
прошёл шаги TypeScript, детерминизма, контрактов/browser gate, 55 smoke-проверок
и оба `cf-play check`. Пробы `check:mission`, `cf-play cycles`, `playthrough:exam`,
lint и budget выполнены локально, с их фактическими результатами и средой в
отчёте. Отсутствие отдельного CI-шага не трактуется как невыполнение критерия.

Оракул и пороги не менялись; **удалённых проверок 0**. Фаза 2 и её вердикт
не переписывались, Фаза 4 не объявляется начатой. Это решение заменяет
предыдущую запись NAR-4.9 из [PR #95](https://github.com/Creative36711/narthex/pull/95):
уточнённая карточка определяет источники локальных проб и не требует, чтобы все
команды были запущены в CI.

## Неясно / решил / откат

Неясно: предыдущий вердикт трактовал отсутствие некоторых команд в visual CI как блокер; уточнённая карточка прямо допускает локальные прогоны для этих источников.

Решил: выполнить перечисленные локальные пробы и зафиксировать их фактические результаты; все обязательные критерии пройдены, фазу закрыть датой 2026-10-27.

Откат: если сохранённый вывод, хэш или rc окажется неверным, изменить только вердикт на «Фаза 3 не закрыта» с названием конкретного неподтверждённого критерия; оракул и проверки не ослаблять.
