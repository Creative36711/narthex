# STAB-1.18 — решение по счётчикам smoke
неясно / RC 0 у smoke:core сопровождается 14 зелёными якорями вместо заявленных 55/55; smoke:mission также сохраняет 10 исходных отказов при запуске всех 55 проб.
решил / Не добавлять искусственные проверки, не ослаблять и не пропускать пробы: указать фактические RC и счётчики, а несоответствие smoke:core и оставшиеся владельческие красные проверки передать STAB-1.19/STAB-1.21.
откат / После исправлений в карточках-владельцах повторить оба прогона и заменить это решение только при наличии канонического набора 55 проверок; поведение, пороги и исключения не менять.
