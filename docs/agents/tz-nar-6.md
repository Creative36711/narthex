## 1. Оракул миссии (фиксируется до первой карточки)

Оракул — критерий, а не имя скрипта. Ослабить его можно только ADR `proposed`
с ответом Мастера.

1. **Проект типа «сетки и тактика» показывает другие панели, не трогая код
   студии.**
2. **`src/editor/` не содержит зашитых строк интерфейса** (проверка в CI).
3. **Проект с `mode: code` открывается:** формы подсистемы скрыты, дерево и
   Monaco на месте.
4. **Проект с `mode: off` не теряет данных и честно предупреждает.**
5. **Переключение языка меняет интерфейс без перезапуска.**
6. **Граница пака сохранена:** пак не знает студию, студия не знает пака. API
   панелей и API песочницы заморожены.

## 2. Инварианты

- Панель регистрируется манифестом пака; слоты `left/center/right/bottom/modal`.
- Три уровня раскрытия: основное / расширенное / JSON.
- Проект с неизвестным паком открывается только для чтения и объясняет, что
  поставить.
- `src/editor/` без зашитых строк интерфейса.
- Не трогаются: `src/core/**`, `packs/**`.

## 3. Scope

- `src/editor/**` — редактор проекта.
- `i18n/<lang>.json` — локализация интерфейса (8 языков: `en`, `ru`, `zh-Hans`,
  `ja`, `pt-BR`, `de`, `fr`, `ko`).
- Панели регистрации манифестом пака.
- Три уровня раскрытия (основное / расширенное / JSON).
- Вкладка «Код» (дерево файлов + Monaco), переключатели `core / code / off`
  по возможностям, предупреждение при `off`.
- `Assets & Animation` **не появляется** (нет пайплайна ассетов).
- Два долга: D-04 (`SceneScreen.tsx` ≤ 450 строк — пересмотреть в фазе 5,
  сейчас 414), локализация интерфейса.
