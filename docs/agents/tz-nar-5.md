# ТЗ Координатору: миссия NAR-5 «state-ui и заморозка формата v2»

Версия: **1.0** (2026-10-28). Предыдущая миссия NAR-4 закрыта с вердиктом
«принять»: фаза 3 закрыта, второй рантайм работает, бюджет кадра перезамерен
(`docs/phases.md`, раздел «Вердикт NAR-4.9»).

**Это направление, а не инструкция.** Как именно — решают Координатор и
исполнители. Пробелы закрываются по лестнице [`freedom.md`](./freedom.md) §4.
Вопрос Мастеру — строка в базе «Вопросы» с вариантом по умолчанию, цикл не
встаёт.

## 0. Место в плане

Фаза **4 из десяти** ([`phases.md`](../phases.md) §Фаза 4). Закрыты: фаза 0
(контракты), фаза 1 (ядро), фаза 2 (шов «движок / пак»), фаза 3 (второй
рантайм). Эта миссия открывает фазу 4 и закрывает её — четвёртой миссии «на
добивку» быть не должно.

Смысл фазы: **первый пак с другим «директором»** на том же пошаговом цикле
(`state-ui`: автоматы, карты, интерфейсы, автобой) и **формат проекта, который
становится контрактом**. После этой фазы добавить необязательное поле можно;
изменить смысл существующего — только миграцией (ADR 0003).

## 2. Правила этой миссии

1. **Проверка карточки — команда, а не текст.** В карточке Notion поле
   «Проверка» содержит одну команду, которой приёмка доказывается. Текст
   пересказывают неправильно, команду — нет. Это правило появилось после двух
   возвратов подряд, где критерий был фразой.
2. **Стоп-цена: третий возврат карточки** — не четвёртый круг, а эскалация
   Мастеру строкой в «Вопросах»: «режем объём или меняем подход». Цикл не
   встаёт, но карточка дальше не крутится.
3. **Одна карточка — одна зона записи.** Карточка пака не правит `src/core`; если
   пак без этого не собирается — это находка фазы, а не повод расширить ядро.
4. **Документы меняются в том же PR, что и код.** Иначе Spec Auditor выпишет
   расхождение docs ↔ код, и это блокирующая находка.
5. **Порядок заморозки — после доказательства.** Черновик правила (5.1) пишется
   рано, статус `accepted` (5.10) — только когда пак и игра уже зелёные. Морозить
   формат, не проверенный на третьем жанре, — это зафиксировать ошибку.

## 3. Карточки

Двенадцать карточек. Границы — границы зон записи ([`roles.md`](./roles.md));
номера — тот же идентификатор миссии, что в Notion.

**Что уже есть к началу миссии.** Пункты 3–5 оракула контрактами частично
закрыты ещё до фазы 4: `docs/contracts/examples/project.code-mode.json` содержит
`cap_options` (режимы `code` и `off`), `locales.de.json` описывает локали, а
`examples/invalid/project.cap-off-required.json` — выключенную обязательную
возможность. Поэтому карточка 5.2 не «строит формат», а **сверяет** покрытие и
добирает пробелы. Выдумывать работу, которая уже сделана, — тоже дефект.

### 5.1 — Черновик правила заморозки (Architect)

- ADR `docs/contracts/adr/0015-format-freeze.md`, статус **`proposed`**: что
  считается замороженным полем, что разрешено добавлять, как оформляется
  миграция. Таблица полей `project.json` и `pack.json` с пометками «нельзя
  менять» / «можно добавлять».
- Раздел «Заморозка» в `docs/contracts/format-v2.md` со ссылкой на ADR и явным
  правилом: `accepted` ставится **не здесь**, а карточкой 5.10 — после того, как
  пак и игра-пример зелёные.
- **Проверка:** `npm run check:contracts && npm run check:decisions`.
- **Не делает:** не ставит `accepted`, не пишет код, не трогает `src/`.

### 5.2 — Контракты формата v2: сверка с оракулом (Data/Schema)

- Сверить пункты 3–5 оракула с тем, что уже проверяется: `cap_options`,
  `languages`/`default_language`/`locales`, `code`, негативный пример с
  выключенной обязательной возможностью.
- Добрать только то, чего не хватает: например, позитивный пример проекта
  `state-ui` (появится после 5.3) и пример `pack.json` с `provides.seams` для
  нового пака.
- **Проверка:** `npm run check:contracts` — позитивные примеры проходят,
  негативные отклоняются, число проверок не уменьшилось.
- **Отчёт:** в `_tools/reports/NAR-5.2.md` — таблица «пункт оракула → чем
  покрыт → команда». Если покрытие полное, карточка закрывается этой таблицей
  без правок схем.

## 4. Риски и что с ними делать

| Риск | Признак | Действие |
| --- | --- | --- |
| Заморозили формат раньше доказательства | 5.10 идёт до 5.5 | Остановить, вернуть порядок: сначала игра, потом `accepted` |
| Пак потребовал правок ядра | диф `src/core/**` ≠ 0 | Это провал шва: карточка в «Вопросы», а не расширение ядра |
| D-02 «разобрали», а поведение поплыло | сейв-тесты изменились | Возврат: тесты не правятся, правится перенос |
| Корпус совместимости стал «зелёным по договорённости» | проекты в корпусе подогнаны под результат | Корпус собирается из существующих `public/campaigns` и `_tools/projects`, а не пишется заново |
| Гейт заморозки блокирует законное добавление поля | rc ≠ 0 на добавлении | Разрешение добавлять — часть контракта: гейт падает только на удалении и переименовании |
