# Инструменты агента: что есть, что ставить и чего не делать

Документ для всех ролей, которые работают в песочнице. Он отвечает на один
вопрос: **чем агенту можно пользоваться, чтобы это пережило следующий ход**.

Проверять среду — командой, а не памятью:

```bash
npm run doctor            # паспорт: версии, инструменты, готовность репозитория
npm run doctor -- --json  # то же машинно, для отчёта миссии
npm run doctor -- --net   # плюс достижимость разрешённых хостов
```

`doctor` ничего не ставит и не меняет. Если он говорит «готовность: нужен
`npm ci`» — начинай с `npm ci`.

## 1. Главное правило: инструмент — это команда, а не бинарь

Снапшот платформы хранит **рабочее дерево репозитория**, и только его. Не
переживают ход:

| Что | Почему |
| --- | --- |
| `node_modules` | каталог исключён из снапшота; ставится `npm ci` |
| `~/.npm`, `~/.cache`, pip-кэш | кэши не входят в снапшот |
| `/tmp` | временные файлы, распакованные архивы |
| пакеты, поставленные `apt`/`pip` вне проекта | окружение образа пересоздаётся |
| сам клон репозитория | приходит снимком: сначала `git fetch` + `git reset --hard origin/main` |

Отсюда правило, которым проверяется любая идея «давайте поставим заранее»:
**инструмент допустим, если он ставится из npm или PyPI без postinstall-загрузок
с других хостов и занимает секунды.** Всё остальное — либо ломается на TLS, либо
качается каждый ход заново.

## 2. Что есть всегда

Проверено в этой среде 2026-10-28 (`npm run doctor`):

| Инструмент | Версия | Для чего |
| --- | --- | --- |
| node / npm | 22.22.3 / 10.9.8 | все гейты, `cf-play`, скрипты |
| git / gh | есть | ветки, PR, проверки CI |
| python3 / pip3 | 3.11.2 | `scripts/cutout-chromakey.py`, python-пакеты |
| ImageMagick 6 | `convert`, `montage`, `compare`, `identify` | ресайз, хромакей, **контактный лист**, **golden frames** |
| jq, unzip | есть | разбор JSON, распаковка кита |
| браузер | Chromium через `scripts/visual/local-browser.mjs` | живая проверка экранов |

Машина: 2 ядра, ~3.8 ГБ RAM, ~18 ГБ свободного диска, **не root**. Версия и
железо попадают в отчёт миссии — это требование к бюджетам, а не любопытство.

## 3. Что ставится быстро (проверено)

| Пакет | Откуда | Время | Размер |
| --- | --- | --- | --- |
| `sharp` (libvips 8.18.7) | npm | 2.2 с | 30 МБ |
| `pygltflib` | PyPI | 0.8 с | 27 КБ |
| `@gltf-transform` | npm | секунды | — |

Ставить их в `devDependencies` имеет смысл только когда появляется задача,
которая без них не решается. Проверка «на будущее» в `dependencies` — это
`npm ci` на 30 МБ медленнее у каждого агента и в CI.

## 4. Что не ставится и чем заменяется

| Хочу | Что происходит | Замена |
| --- | --- | --- |
| **Blender** | `apt-get install blender` → «Unable to locate package» (репозиториев Debian нет среди разрешённых хостов); `download.blender.org` недоступен; `bpy` — колесо **519 МБ**, распаковка ~1.3 ГБ, только под Python 3.11 (то есть Blender 4.2) | Своя геометрия: модульный риг кодом (ADR 0007). Внешние модели — `.glb` от человека |
| **ffmpeg** | в образе нет; `ffmpeg-static` тянет бинарь с GitHub и падает на `UNABLE_TO_VERIFY_LEAF_SIGNATURE` | ImageMagick для кадров; для видео — `montage`/`convert` по кадрам; длительность аудио не проверяется |
| **Playwright** | браузер качается с закрытого домена, `--with-deps` требует root | `@sparticuz/chromium` + `scripts/visual/local-browser.mjs` — работает |
| **apt-пакеты** | не root, репозитории закрыты | npm/PyPI или системные инструменты образа |

Если инструмент понадобился, а замена хуже — это повод для карточки Tools с
замером, а не для ручной установки в песочницу: ручная установка не переживёт
ход и не попадёт в отчёт.

## 5. Медиа: проверка вместо глаз

```bash
npm run media:check          # кампании: формат, размеры, вес, хромакей, дубликаты
npm run media:check -- --json
```

Что ловит:

- **сигнатуру вместо расширения** — `fake.png` с HTML внутри (реальный дефект
  фазы 2: 27 «картинок» вместо изображений);
- **остаток хромакея** — доля непрозрачных пикселей чистого зелёного выше 0.5 %;
  бирюза не считается фоном (та же логика, что в `--heal` у
  `cutout-chromakey.py`);
- **вес** — 4 МБ на изображение, 8 МБ на аудио;
- **устаревшие объявления** — путь в `known_absent_images`, который вдруг
  появился в репозитории;
- **дубликаты** по sha256 (предупреждение, не провал).

Чего не ловит (честно): длительность и битрейт звука, декодирование видео,
«красиво ли». Красота — к человеку и визуальному аудитору.

Гейт входит в `check:contracts`: кампания с подменённым файлом роняет приёмку
фазы, а не «находится глазами» через месяц.

## 6. 3D и анимация: как это делается без Blender

Решение — [ADR 0007](../contracts/adr/0007-modular-rig.md): риг модульный,
детали жёсткие, скиннинга и весов нет, анимация — кейфреймы трансформаций
(`part`, `socket`, `assembly`, `clip`, `palette`). То есть **ассет — это
данные**, а данные агент пишет и проверяет сам.

Три проверки из плана фазы 8, уже просчитанные на этой машине:

| Проверка | Как | Замер |
| --- | --- | --- |
| Контактный лист 12–16 кадров | поза проецируется тем же кодом, что рисует игру, сетка собирается `montage` | 3 кадра — **30 мс** |
| Golden frames | `compare -metric RMSE` между кадром и эталоном | **9 мс** |
| Метрики движения | замыкание цикла и поппинг считаются по числам из `clip`, без рендера | мгновенно |

Blender остаётся инструментом человека: художник отдаёт `.glb`, агент валидирует
его (`@gltf-transform`) и запекает в формат рига. Роль `Assets & Animation`
появляется на фазе 8 — раньше у неё нет зоны записи.

## 7. Чеклист перед первой правкой

1. `git fetch origin main && git reset --hard origin/main` — дерево как в main
   (ритуал из [`sandbox.md`](./sandbox.md)).
2. `git switch -c nar/<номер> origin/main`.
3. `npm ci` — если `doctor` сказал, что окружение не готово.
4. `npm run doctor` — прочитать, чего нет, и не тратить ход на недоступное.
5. `npm run doctor -- --json` — вставить в отчёт миссии: машина и версии нужны
   бюджетам и сравнениям.

Квоты хода: **10 изображений и 10 аудиоклипов** — планируются блоками
([`generation-quotas.md`](./generation-quotas.md)), а не «добью остаток».
