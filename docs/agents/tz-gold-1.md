# ТЗ Координатору: миссия GOLD-1 «Золотая кампания «Каркас»»

Версия: **1.0** (2026-10-29). Предыдущая миссия NAR-5 закрыта с вердиктом
«принять»: фаза 4 закрыта, формат v2 заморожен, пак state-ui играется до конца
(`docs/phases.md`, раздел «Вердикт NAR-5»).

**Это направление, а не инструкция.** Как именно — решают Координатор и
исполнители. Пробелы закрываются по лестнице [`freedom.md`](./freedom.md) §4.
Вопрос Мастеру — строка в базе «Вопросы» с вариантом по умолчанию, цикл не
встаёт.

## 0. Место в Pläne

**Вне фаз.** GOLD-1 не относится ни к одной из десяти фаз (`docs/phases.md`,
раздел «Сквозное: золотая кампания»). Кампания заводится один раз и дальше
служит проверкой для фаз 3, 4, 5, 9 и 10. Миссия — одна, не «фаза золотой
кампании».

Кампания уже написана и лежит во внешнем репозитории
`Creative36711/campaign-1` («Каркас: Дело о седьмой помпе», 5–7 часов, 12 сцен,
5 глав, 9 концовок, 462 изображения, 372 файла озвучки, 1287 файлов, 192 МБ).
Правило платформы: файлы не хостятся (`vision.md` §8). Архив остаётся в своём
репозитории; в платформу приходит только скрипт импорта по `manifest_url` +
`sha256` в каталог `.golden/karkas/` (в `.gitignore`).

## 1. Оракул миссии (фиксируется до первой карточки)

Оракул — критерий, а не имя скрипта. Ослабить его можно только ADR `proposed`
с ответом Мастера.

1. **Кампания импортируется без правок.** Скрипт забирает релиз
   `campaign-1` в `.golden/karkas/` и открывает в игре. Зафиксировано: что
   падает, что предупреждает `audit:campaign`, что не читается после
   `engine_version 0.8.0` → `0.9.0`.
2. **`npm run audit:campaign -- .golden/karkas` → 0 ошибок.** Кампания не
   «золотая», если есть находки.
3. **`cf-play check .golden/karkas` → 0.** Кампания проходит проверку графа
   и статики без ошибок и предупреждений.
4. **60 минут игры по скрипту → 0 `pageerror`, 0 пустых фонов, звук меню
   играет.** Скрипт проходит: меню → создание героя → шлюз → машинный зал →
   первая улика.
5. **Сохранение и загрузка посреди кампании не теряют флаги и время.**
6. **Три концовки достижимы скриптом.**
7. **Скрипт `npm run playthrough:golden` добавлен.** Он тянет архив по
   `manifest_url` + `sha256`, распаковывает в `.golden/`, проходит шаги 2–4.
   В CI — отдельной джобой (192 МБ на каждый коммит дорого); до появления
   скрипта шаги 1–6 делаются вручную.

## 2. Инварианты

- Кампания остаётся во внешнем репозитории `Creative36711/campaign-1`.
- Каталог `.golden/karkas/` в `.gitignore` — файлы не коммитятся в платформу.
- Не трогаются: `src/core/**`, `packs/**`, `docs/contracts/**`.

## 3. Scope

- Скрипт импорта кампании.
- Каталог `.golden/` (в `.gitignore`).
- Пробы `audit:campaign` и `cf-play check` на импорте.
- Скрипт прохождения 60 минут (`playthrough:golden`).
- Карточки с числами для всего, что сломалось при импорте (расхождения
  0.8.0 → 0.9.0, длительные действия, `duration_actions`).

## 4. Зависимости

- Фаза 4 закрыта — миссию можно заводить.
- Внешний репозиторий `Creative36711/campaign-1` доступен.
