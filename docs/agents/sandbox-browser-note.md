# Примечание к песочнице: браузер есть, проверка игрой обязательна

Этот файл — короткая памятка, которую не надо искать по `docs/agents/*`.
Полные инструкции: [`browser.md`](./browser.md), [`visual.md`](./visual.md).

## Факт

В песочнице агента поднимается настоящий Chromium 131 без root:

```bash
npm i --no-save @sparticuz/chromium@131 playwright-core@1.49.1
npm run build
npx vite preview --port 4173 --host 0.0.0.0 --strictPort   # в start_process
node scripts/visual/shot.mjs http://localhost:4173 out/x.png --console
npm run playthrough -- http://localhost:4173 out/play
```

`npm run check:browser-gate` (входит в `check:contracts`) не даст вернуть в
репозиторий фразы «браузера в песочнице нет», «браузер не запускается»,
«пиксели в песочнице невозможно». Если он красный — чини текст, а не оракул.

## Правило приёмки

Ни одна фаза, карточка или PR не считаются проверенными, пока в отчёте нет
браузерного прохождения: PNG-экранов, текста экрана, ошибок консоли. CLI,
`cf-play explore`, прямой вызов симуляции и чтение исходников — **не замена**.
Формальная причина: `check:contracts` теперь включает `check:browser-gate`,
а `visual.yml` запускает `playthrough.mjs` и падает, если маршрут игрока не
проходится.

## Почему это появилось

26.10 миссию NAR-2 приняли по зелёным контрактам и текстовому прохождению.
Настоящий браузер, запущенный сразу после, показал падение FMV-проекта
(`nav.area.x`), битые пути к ассетам и отсутствие потребителей у пака
`adventure`. Вывод записан в `docs/decisions/NAR-2.md` (D-072) и в новой
миссии NAR-3.
