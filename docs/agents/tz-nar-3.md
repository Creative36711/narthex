# ТЗ Координатору: миссия NAR-3 «Играбельность»

Версия: **1.0** (2026-10-26). Предыдущая миссия NAR-2 («Шов движок / пак»)
закрыта с вердиктом «принять», но её приёмка не открывала игру в браузере.
Основание: [D-072](../decisions/NAR-2.22.md).

**Это направление, а не инструкция.** Как именно — решают Координатор и
исполнители. Все пробелы закрываются по лестнице [`freedom.md`](./freedom.md)
§4. Вопрос Мастеру — строка в базе «Вопросы» с вариантом по умолчанию, цикл не
встаёт.

## 0. Место в плане

Фаза 2 из [десяти](../phases.md) **не закрыта**: на паках `adventure` и `fmv`
нет играбельного проекта. Миссия NAR-3 — добивочный проход, который впервые
закрывает фазу 2 по настоящему оракулу. Фаза 3 (второй рантайм realtime)
**начинается только после** зелёного `npm run playthrough` на паках фазы 2.

Новые паки не создаём, пока ни один пак не играется руками.

## 1. Оракул миссии (фиксируется до первой карточки)

Обязательные команды, каждая — с кодом возврата 0 и выводом в отчёте:

```bash
npx tsc -b
npm run check:contracts          # включает check:browser-gate
npm run check:brand
npm run check:version
npm run smoke:core
npm run build
npm run playthrough -- http://localhost:4173 out/play   # собранный билд + vite preview
node public/ai/cf-play.mjs check public/campaigns/ash-of-caerden
node public/ai/cf-play.mjs check public/campaigns/ash-of-caerden-adventure
```

Плюс **отчёт-прохождение** (`out/play/report.md`, PNG как минимум шести
экранов) смотренный глазами: на снимках не должно быть «Фон сцены не
загрузился», «Игра столкнулась с ошибкой», битых `<img>` вместо портретов,
сырых `id` вместо имён NPC, «Кампаний пока нет» там, где игрок ждёт игру.

Сквозные гейты из [`phases.md`](../phases.md) действуют целиком. Ослабить
оракул — только ADR `proposed` с ответом Мастера.

## 2. Что построить

### Карточка 3.1 — Adventure: соединение пака с экраном

- `src/` получает потребителя `adventure.*`: клик по сцене →
  `adventure_click` / `adventure_cursor`, отрисовка `adventure.avatar`,
  `adventure.message`, `adventure.ending`.
- `PackPanelWorkbench.tsx` / `packPanels.ts` показывают панель adventure
  (не «пак неизвестен»).
- playkit `act()` учится `adventure_click` / `adventure_cursor`, чтобы маршрут
  можно было записать в CI одной командой.
- Проект `public/campaigns/ash-of-caerden-adventure` проходится от старта до
  `ending_gate_unlocked` **в браузере**: ходьба, осмотр, взятие двух предметов,
  соединение в мазь, разговор, загадка `gate_sigils` с неверной и верной
  последовательностью.

### Карточка 3.2 — FMV: плеер и ветвление

- `src/shared/CutscenePlayer.tsx` (или новый компонент) получает режим `fmv`:
  `<video>` с предзагрузкой следующего фрагмента, субтитрами вне журнала,
  выбором после фрагмента без пустого кадра.
- `public/campaigns/fmv-crossing` перестаёт быть «проектом, который роняет
  игру»: браузерный маршрут открывает его, показывает посте́р, проигрывает
  фрагмент и даёт выбор.
- Регрессия на D-072: смоук, который подаёт сцену без `area` и проверяет, что
  приложение не падает.

### Карточка 3.3 — Играбельный проект в поставке

- Решить противоречие: `public/campaigns/index.json` намеренно пуст
  (см. `60a2da5`, `smoke:no-campaign`), а оракул требует играбельный проект.
  Варианты: штатный стартовый проект в реестре + отдельный сценарий «пустой
  реестр» для смоука, либо явный выбор проекта на старте с понятным путём
  игрока. Решение зафиксировать ADR.
- Полигоны разработки уже помечены (26.10): префикс `[DEV]` в `title`,
  маркер `dev-fixture.json`, реестр `docs/agents/dev-campaigns.md`, страж
  `check:dev-campaigns`. Новые тестовые кампании агенты создают по правилам
  этого документа: имя с `[DEV]`, каталог `__dev_*`, уборка в `finally`.
  Карточка проверяет, что страж остаётся зелёным и не ослабляется.
- 27 отсутствующих изображений — **намеренная фикстура**, а не поломка. Но
  игрок не должен видеть «Фон сцены не загрузился» как ошибку: либо генерация
  плейсхолдеров на месте, либо честный текст «демо-проект без графики» без
  красных плашек. `npm run audit:campaign` для демо-проекта обязан дать
  внятный результат (0 или явно помеченный fixture-режим), а не 27 ERROR.
  Сами 27 картинок лежат в истории git (`a3bea9a`): если кампанию вернут в
  витрину, они восстанавливаются, а не генерируются (D-075).

### Карточка 3.5 — Экзамен «прохождение»

- `scripts/visual/playthrough.mjs` расширяется до маршрутов по **обоим** пакам
  (adventure и fmv), а не только по narrative + smoke FMV.
- `visual.yml` складывает PNG в артефакт, отчёт содержит число шагов и
  список ошибок консоли.
- Любая новая карточка в «Запросах» с полем UI в Scope обязана иметь в
  Acceptance строку с командой браузерного прохождения.

- Ослаблять оракул, удалять шаги маршрута или помечать находки как
  «ожидаемо» без ADR.
- Генерировать медиа для dev-полигонов и обходить квоту Arena: 10 изображений
  и 10 аудиоклипов за ход ([`generation-quotas.md`](./generation-quotas.md)).
