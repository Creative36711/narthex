# Гейт размера модулей

`npm run check:module-size` считает физические строки кода в изменённых/созданных файлах-модулях под `src/**` и `packs/**`; `src/core/engine.ts` проверяется всегда как фасад. Максимум — `450` строк для обычного модуля и `600` для `engine.ts`. Пороги заданы константами в `scripts/check-module-size.mts`, а не переменными окружения или конфигурацией.

Скрипт сравнивает дерево с `origin/main`, добавляя неотслеживаемые исходники. Поэтому новый или изменённый модуль выше лимита завершает проверку с ненулевым кодом и сообщает фактическое число строк и предел. Неизменённые `src/core/combat.ts` и `src/core/savemigrate.ts` печатаются как внешний долг, но не блокируют несвязанные изменения; при изменении эти файлы проверяются по общему лимиту `450`.

Каждый запуск сначала выполняет фикстуры на лету:

```text
fixture (a) changed module 451 lines: PASS — rc=1, lines=451, limit=450
fixture (b) changed module 450 lines: PASS — rc=0, lines=450, limit=450
fixture (c) engine.ts 600 lines: PASS — rc=0, lines=600, limit=600
fixture (d) engine.ts 601 lines: PASS — rc=1, lines=601, limit=600
```

Команда входит в `npm run check:contracts` рядом с проверками паков, границы core/packs и статусов решений.
