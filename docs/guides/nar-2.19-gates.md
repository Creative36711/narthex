# Гейты решений и размера руководства

## Проверка статусов решений

Запустите `npm run check:decisions` (она также включена в `npm run check:contracts`). Скрипт проверяет `docs/decisions/*.md`:

- отсутствие поля `Статус:` допустимо для старых журналов;
- если поле есть, значение должно быть одним из `proposed`, `accepted`, `rejected`, `superseded`;
- для `accepted` и `rejected` обязательны непустое `Дата решения: YYYY-MM-DD` и непустое `Решил:`;
- `proposed` не блокирует проверку: скрипт печатает список таких ADR, дату из поля `Дата:` и возраст в календарных днях UTC. Если дату прочитать нельзя, возраст выводится как `unknown`, но статус `proposed` всё равно остаётся информационным.

Проверка сама запускает временные фикстуры: журнал без статуса принимается; неизвестный статус и финальные решения без обязательных метаданных отклоняются; `proposed` с датой отображается с рассчитанным возрастом.

## Реальный предел полного руководства

`npm run check:guide` проверяет, что `public/ai/campaign-guide.md` побайтно совпадает с `docs/ai-campaign-guide.md`, и что каждый файл не превышает `524288` байт (512 КиБ). Размер измеряется в UTF-8 байтах. Проверка также выполняет прежние проверки CLI, сборки и распакованного AI-kit.

В тесте функции ограничения зафиксированы границы: `268683` байта принимаются, `524289` байт отклоняются сообщением, содержащим фактический размер и предел.
