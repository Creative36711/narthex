# Быстрый старт cf-play: пример и объяснение ошибок

Эта короткая памятка покрывает только инструменты кита. Полный формат кампании остаётся в `public/ai/campaign-guide.md`; для обычного запуска `cf-play` не нужно читать его целиком.

Эталонный пример — опубликованная кампания «Пепел Каэрдена». Команда `example` запускает для неё ту же проверку, что `cf-play check`, с фиксированными seeds 1–5. При успешном запуске вывод сохраняет эталон: 10 сцен, 8 локаций, 6 диалогов, 21 узел Ink, 0 ошибок, 8 предупреждений, 5 смертей и покрытие 6 из 10 сцен. Сам пример не меняет кампанию и не пишет отчёты в неё.

## В исходном клоне Narthex

После установки зависимостей:

```bash
npm run play -- example
npm run play -- explain ink_missing_knot
```

## В собранном файле из клона

```bash
node public/ai/cf-play.mjs example
node public/ai/cf-play.mjs explain ink_missing_knot
```

## В распакованном чемодане

Запускайте из корня кампании после распаковки `__chronicle_ai__-kit.zip`:

```bash
node __chronicle_ai__/cf-play.mjs example
node __chronicle_ai__/cf-play.mjs explain ink_missing_knot
```

В чемодан входит копия того же эталона в `__chronicle_ai__/examples/narrative`, поэтому `example` не зависит от репозитория Narthex и сети. Скрипт упаковки и проверка команд используют одну опубликованную копию кампании; существующий гейт `check:campaigns` отдельно сверяет её с источником в паке.

`explain` принимает любой диагностический код статического narrative-анализатора. Для известного кода он печатает причину, место поиска и минимальный способ исправления и возвращает `0`. Команды выше используют один рабочий пример: замените последний аргумент кодом из своего отчёта. Неизвестный код возвращает `2` и выводит каталог поддерживаемых кодов; второй список в этой памятке или полном справочнике не ведётся. Старый вызов `explain --catalogue` по-прежнему показывает установленные паки.

Все шесть команд в fenced-блоках исполняются `npm run check:guide`: команды проверяются на исходниках, собранном bundle и после распаковки чемодана. Этот же скрипт проверяет цифры эталона, все коды `explain` и ожидаемый код `2` для неизвестного кода.
