# 9. Лицензия и авторство

Narthex — самостоятельное программное обеспечение. Названия игровых
систем (например, Basic Roleplaying) упоминаются внутри этой книги только
как обозначение совместимости идей: текст книги и реализацию создали
«с нуля» и без заимствования.

Если конкретная распространяемая работа включает Open Game Content из
официальных системных документов, издателю следует вставить актуальную
атрибуцию, разграничить Product Identity и Open Game Content и выполнить
остальные требования открытой лицензии Chaosium в последней версии на
официальных ресурсах Chaosium.

Текст и программный код Narthex распространяются по выбору
автора/издателя. Текст этой книги создан для мастеров: используйте его и
перепечатывайте в своих кампаниях, подписывая ссылку на исходный проект.
