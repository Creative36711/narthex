# 7. Работа с внешним ИИ: единое задание, полный пакет, проверка

Narthex не отправляет кампанию во встроенный ИИ и не вызывает внешний
сервис от вашего имени. Вы выбираете чат/агента сами; редактор подготавливает
задачу и файлы, которые вы ему передадите.

## 7.1. Один помощник вместо двух разрозненных действий

В меню **Инструменты → Задание для ИИ** откройте единый помощник. Он объединяет
старый бриф «Кампания с ИИ» и чемодан агента:

1. выберите, создать новую кампанию или изменить открытую;
2. опишите задачу обычными словами; для новой кампании можно дополнить бриф
   жанром, тоном, масштабом и акцентами;
3. выберите формат результата: полный `.narthex` по умолчанию или
   MonolithDoc JSON для текстовых/структурных правок без бинарных медиа;
4. скачайте собранный пакет и передайте его внешнему ИИ.

В пакет редактирования входят все данные текущей кампании, локальные медиа,
задача мастера, руководство движка, схема, бланк дизайн-документа и последний
отчёт проверки. Он скачивается как AI-task `.narthex`; инструкции и отчёт
находятся в служебной папке `__chronicle_ai__/`. Это не часть кампании:
редактор игнорирует эту папку при импорте результата. Для новой кампании
скачивается `.zip` с задачей и документацией; исходных файлов проекта там нет.

Кнопка **«Скопировать промпт»** — запасной способ перенести инструкцию
вручную. К ней всё равно приложите скачанный архив. Пакет ничего сам не
отправляет и не загружает в сеть.

## 7.2. Выбор формата результата

- **Полный `.narthex`** — основной путь для новой кампании, правок с
  изображениями, музыкой, звуками или видео и для передачи проекта целиком.
  Медиа остаются отдельными файлами внутри ZIP-пакета, а не раздувают JSON.
  - Выбирайте его, если задача затрагивает медиа или нужна автономная копия.
  - Все пути медиа должны быть относительными и вести внутрь архива.
- **MonolithDoc JSON** — удобная лёгкая альтернатива для правки текста и
  структуры без бинарных файлов. Он не переносит новые картинки и звук;
  мастер импортирует его через **Файл → Импорт из JSON**.
  - Выбирайте его для небольших текстовых/структурных правок без новых медиа.

Для нового `.narthex` редактор заранее выдаёт ID кампании и включает его в
задачу агенту. Для нового JSON ID назначит приложение при импорте. При
редактировании существующего проекта ИИ обязан сохранить его ID; переименование
может разорвать связь с сейвами и метапрогрессом.

Если агент создал или скачал изображения, музыку или звуки, попросите его
положить файлы внутрь `.narthex` и использовать относительные пути. Для
скачанных материалов указывайте источник и условия использования. Внешние URL
оставляйте только осознанно: они могут перестать работать, требуют сети и
обычно не входят в офлайн-пакет. Экспорт `.narthex` умеет предложить вшить
доступные внешние файлы.

## 7.3. Дизайн-документ и рамки задачи

Агент должен обновлять `design_doc` при значимых изменениях: сначала записать
замысел и журнал решений, затем в том же ответе выполнить запрос. Это не этап
подтверждения — агент не должен ждать «ок» или задавать вопросы, если может
принять разумные допущения.

Для **редактирования** переданный пакет — источник истины. Не просите агент
создать его заново, если задача — поправить одну сцену или исправить отчёт.
В форме помощника удобно явно указать, что сохранить, что изменить и чего
не добавлять. Если в отчёте есть ошибки, кнопка **«Задание для ИИ с отчётом»**
сама приложит проверку и кампанию — копировать и склеивать их вручную не нужно.

### Граница оформления главного меню

Название и краткое описание кампании (`meta.title`, `meta.description`),
профиль/акцент/шрифты/палитра (`theme.profile`, `theme.accent`,
`theme.fonts`, `theme.tokens`) и оформление меню/финала
(`theme.menu.background`, `theme.menu.dim`, `theme.menu.ken_burns`,
`theme.menu.title_art`, `theme.end.background`) задаются данными кампании. Бренд Narthex, версия движка и подписи
системных кнопок («Новый забег», «Продолжить», «Кампании», «Как играть»,
«Настройки», «Редактор»), как и их расположение, принадлежат интерфейсу
движка. Агент не может переименовать их содержимым кампании: формулируйте
задачу о названии/описании кампании или оформлении, а не о системных кнопках.
Для меню назначайте фон и `title_art` раздельно; не встраивайте в иллюстрации
текст, который уже выводит интерфейс. `theme.custom_css` влияет только на
визуальные правила кампании и не предназначен для имитации системных надписей
или функций.

## 7.4. Проверка: структура → медиа → плейтест

**Инструменты → Проверить кампанию** формирует один отчёт по трём разделам:

1. **Структура и ссылки** — проверка типов полей по JSON Schema, связей между
   сценами, персонажами, квестами, правилами, версий и других известных
   редактору ограничений.
2. **Файлы и медиа** — проверка существования локально упомянутых изображений,
   аудио, видео и шрифтов, а также предупреждения о внешних URL и MIME-типах.
   Внешняя ссылка может требовать сети и не быть включена в пакет.
3. **Плейтест** — показывает, запускался ли ручной тест после последних
   изменений и сохранён ли вывод мастера. Автоматически пройти игру и решить,
   что она работает, эта проверка не может.

Чтобы записать результат прохождения, во время игры нажмите в баннере
**«Записать результат»** и кратко укажите, что проверили и что сломалось.
После этого отчёт можно передать агенту кнопкой **«Задание для ИИ с отчётом»**;
он получит кампанию и все три раздела проверки.

Проверка не оценивает качество сюжета или баланс и не заменяет ручной плейтест.
Если отчёт чистый, это значит, что известные структурные ошибки и отсутствующие
локальные медиа не обнаружены — не то, что кампания уже прошла игровой тест.

## 7.5. Надёжный цикл работы

1. Подготовьте задачу и скачайте AI-пакет из редактора.
2. Отправьте архив внешнему агенту с кратким объяснением задачи.
3. Попросите вернуть готовый `.narthex` (или JSON, если выбрали JSON-режим).
4. Импортируйте результат. Для конфликтующего `.narthex` выберите обновление
   существующей кампании или отдельную копию; ничего не перезаписывается молча.
5. Запустите проверку, изучите разделы, исправьте ошибки и пройдите плейтест.
6. При необходимости откройте задачу повторно через помощник: текущая кампания,
   отчёт и новые инструкции будут собраны вместе.

## Коротко о правилах для ИИ

- Следовать приложенным руководству и схеме; не придумывать поля и механики.
- Не менять `campaign.id` при редактировании и не переименовывать ID сущностей.
- Для отдельной новой кампании использовать назначенный приложением ID.
- Не создавать новую кампанию с нуля при задаче на исправление существующей.
- Упаковывать медиа отдельными файлами и не добавлять случайные временные URL.
- Возвращать `.narthex` для полной кампании; JSON — только для задач без новых
  бинарных медиа.
