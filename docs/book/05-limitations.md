# 5. Чего в движке пока нет

Аудит механик. Источники: код движка (`src/core/`, `src/shared/types.ts`,
`src/shared/compat.ts`) и книга **Basic Roleplaying: Universal Game Engine**
(Chaosium, ORC) — сверены главы 1–11.

Правило простое: **помеченное «нет» не обещайте игрокам как встроенную
механику.** Обход, собранный из сцен, правил и эффектов, — авторское решение
мастера, а не подсистема движка: опишите его игрокам до начала забега и
держите условия в самой кампании.

Этот файл — только по делу: всё, что реализовано на 100 %, убрано. Осталось
частично реализованное, спорное и совсем не сделанное. Ищите сделанное
в [справочнике механик](04-reference.md).

Статусы в таблицах:

| Статус | Значение |
| --- | --- |
| **нет** | подсистемы не существует, собрать «руками» можно только имитацию |
| **частично** | есть деталь механизма, но не вся механика |
| **обход** | встроенного нет, но имитация получается убедительной |

## 5.1 Чего нет: сверка с BRP по главам

### Глава 2. Персонажи

| Механика | Статус | Примечание |
| --- | --- | --- |
| Перераспределение очков между характеристиками | нет | только ручная докрутка бюджета |
| Возраст, происхождение-биография, имя | частично | имя — если `choose_name`; биография — текстом в описании кампании |
| Нечеловеческие персонажи | частично | характеристики НПС любые, но форма героя одна и та же |

### Глава 3. Навыки

| Механика | Статус | Примечание |
| --- | --- | --- |
| Базовый шанс навыка от характеристик (Скрытность = Ловкость ×2 и т. п.) | нет | навык — просто число из реестра кампании |
| Групповые сцепленные проверки | частично | подмога есть (`assist_entity`/`assist_skill` у `stat_check`: союзник с навыком ≥ порога аугмента даёт +20); полноценных сцепленных групповых бросков нет |

### Глава 4. Силы

| Механика | Статус | Примечание |
| --- | --- | --- |
| Магия, мутации, психика, колдовство, суперсилы | частично | школа = навык в реестре + способности с MP и кулдаунами; есть подготовка в слоты (`meta.magic.slots`, `prepare`) и магический откат при критической неудаче (`backlash_table`). Нет: системы изучения заклинаний, стоимости заучивания, ветки школ |

Магия собирается из движковых деталей: навык школы + способности с MP +
кулдауны; `meta.magic.slots` включает подготовку в слоты (герой чарует в листе
персонажа), `backlash_table` — откат при критической неудаче применения.
Изучение — флагами и записями кодекса. Не соберётся: полноценная экономика
заучивания заклинаний и разные ветки школ — это мастерское контентное решение.

### Глава 6. Бой

| Механика | Статус | Примечание |
| --- | --- | --- |
| Хит-локации | да (опционально, выключено по умолчанию) | `meta.combat.hit_locations`: таблица d100, множители урона, локальная броня, статусы локации |
| Ловушки и взлом | обход (склизко) | проверка навыка + эффект; самой подсистемы нет (см. обходные пути) |
| Укрытия | да (опционально) | `meta.combat.cover` + кисть «Укрытие» в редакторе арены; штраф дальнобойным, на движение/рукопашку не влияет |
| Высота и рельеф | нет | гексы плоские |
| Таблицы критических попаданий | да | `meta.combat.crit_table` (максимум урона без брони, двойной урон с бронёй, разоружение, статус) и `meta.combat.fumble_table` обе по весам; без таблиц — книжный крит и простой промах |
| Фланкирование и удар в спину | нет | разворот фигурки — косметика; сценарий засады покрывает удар из скрытности |
| Конный, воздушный, подводный бой; транспорт | нет | — |

### Глава 7. Частные правила (Spot Rules)

| Механика | Статус | Примечание |

| Механика | Статус | Примечание |

## 5.2 Механики, которых нет в BRP, но которые напрашиваются

То, чего просит сам жанр текстового рогалика, а не книга.

**Комфорт игрока**

| Механика | Статус | Примечание |
| --- | --- | --- |
| Откат хода / отмена действия в бою | нет | есть автосохранение, отмены хода нет (undo — только в редакторе) |
| Уровень сложности как настройка игрока | да (по решению мастера) | `meta.difficulties`: пресеты мастера (урон врагов, голод, цены, запрет автосейвов), игрок выбирает при старте; нет списка — выбора нет |

## 5.3 Обходные пути: рецепты

| Хочется | Как собрать сейчас |
| --- | --- |
| Удачу как очковую трату «perk+задело» | переменная + заранее описанные правила траты; игрок должен знать правила до забега. (Встроенные очки удачи `meta.luck` есть — здесь речь о нестандартных тратах) |
| Магию (экзотика) | к движковым слотам/откату — изучение заклинаний флагами и записями кодекса |
| Уровень сложности проверок нестандартными долями | `skill_check`/`stat_check` принимают сложность `SkillDifficulty` ×2/×1/½/¼; другие доли — ручным `modifier` |

## 5.4 Осознанные исключения текущего этапа

Это не «не нужно», а «не сейчас» — с зафиксированной точкой возврата:

1. **Доступность (accessibility): крупный шрифт, режим для дальтоников, экранный диктор.**
   Сейчас частично покрыто темами редактора и настройками звука. Возврат — отдельным
   блоком «доступность» в HUD со своим профилем оформления (`profiles`) и ARIA-разметкой
   боевого экрана.
2. **Локализация интерфейса.** Движок и UI — русские; тексты кампаний язык не ограничивают.
   Возврат — вынести строки интерфейса в словарь и подключить выбор языка.
3. **Мобильная и тач-раскладка.** Бой и карта построены под курсор/точный клик.
   Возврат — отдельная тема верстки (крупные сенсорные мишени, жесты) после
   стабилизации мета-операций.
4. **Процедурная генерация мира/подземелий.** В движке — рандомизация добычи,
   встреч на дорогах и таблиц событий/генераторов. Полноценный процген локаций —
   отдельный проектный объём: нужна процедурная топология гексов, балансировка и валидация
   связности. Возврат — этапом после воркшопа.
5. **New Game+.** Режим «пройденная игра + новый забег с сохранением части героя» —
   пересчёт силы мира/врагов под сохранённые навыки без дисбаланса. Архитектурные крюки
   уже есть: мета-прогресс с усилениями и счётчиками, множители сложности как готовая
   механика (`meta.difficulties`). Возврат — поверх мета-хранилища: профиль переноса
   (что сохранить: навыки/экипировку/метавалюту) и применение пресетов к повторному забегу.
6. **Воркшоп и обмен кампаниями.** Архитектура спроектирована ([`docs/workshop.md`](../workshop.md)):
   кампании лежат на GitHub мастера, воркшоп хранит только ссылки; скачивание — в Tauri-приложении
   (плагин http, обход CORS), большие ассеты — через релизы. Возврат — следующей фазой в
   десктопной оболочке.

Дороже всего и потому в конец: процедурная генерация мира, динамическая
экономика, симуляция потребностей НПС.

## 5.5 Как поддерживать этот файл

Список живёт вместе с кодом. Добавили механику в движок — уберите строку
отсюда и обновите [справочник механик](04-reference.md). Обнаружили, что
в движке чего-то нет, — добавьте строку со статусом и обходом, чтобы мастер
не узнал об этом на середине забега.

Сверка с формулировками BRP: [BRP SRD и лицензия](https://brp.chaosium.com/).
Не копируйте в книгу текст коммерческих изданий — см. [раздел об авторстве](06-license.md).
