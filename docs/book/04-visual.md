# 4. Визуальная часть: картинка, анимация, атмосфера, темы

Оформление кампании собирается из четырёх слоёв: **кадр** (картинки),
**движение** (анимация и камера), **атмосфера** (погода, свет суток) и
**тема интерфейса**. Ниже — как настроить каждый слой. Всё описанное
редактируется в конструкторах редактора, без кода.

## 4.1. Картинки: файлы и art-примитивы

**Файловые изображения.** Рядом с полем картинки есть кнопка загрузки.
Редактор сам положит файл в `assets/img/` кампании и впишет путь. Подходят
PNG, JPG, WEBP. Можно просто указать ссылку (http/https) — тогда картинка
подтянется при игре онлайн, а офлайн-экспорт предложит «вшить» внешние
ссылки в пакет.

**Art-примитивы.** Если файла нет, сцену и катсцену можно собрать из
встроенного рисунка (ArtDoc): силуэты, формы, градиенты. Хорошая практика —
сделать весь проект на art-примитивах, а файлы добавить позже.

### Преемственность состояний и консистентность изображений (Visual Continuity)

При создании состояний одного объекта (эмоции персонажа, день/ночь в сцене, открытый/закрытый сундук, фигурка боя по портрету) критически важно сохранять визуальную узнаваемость:
- Всегда визуально осматривайте базовый ассет перед созданием или генерацией производного состояния.
- Фиксируйте ключевые якоря внешности: черты лица, возраст, одежду, форму носа/глаз, шрамы (для NPC); архитектуру, перспективу и ориентиры зданий (для комнат и сцен).
- Меняйте только целевой параметр (мимику, время суток, позу), чтобы герой не превращался в другого человека, а сцена оставалась той же локацией.
- Для спрайтов и фигурок боя, требующих прозрачного фона, генерируйте силуэт на однородном контрастном хромакее (`#00FF00`) и вырезайте фон скриптом `scripts/cutout-chromakey.py` (нейросети рисуют фейковую шахматку вместо настоящего альфа-канала).

## 4.2. Движение: анимация и камера

### Кадровая анимация (оживление)

Почти у любого поля картинки есть кнопка **«Оживить»**: несколько кадров
сменяют друг друга по таймеру — мигающий фонарь, пламя очага. Настройки:
список кадров, темп (кадров в секунду), зацикливание.

### Лист-анимация (спрайт-лист N×M)

Проще некуда: один файл, где кадры лежат сеткой. Кнопка **«Оживить (лист
N×M)»** — укажите колонки, строки и темп. Движок сам делит файл на кадры.
Так появляются дым, вода, покачивание деревьев — без нарезки по файлам.

### Камера: пан-зум у фона и слайдов

У фона каждого состояния сцены и у слайда катсцены есть строка
**«Движение камеры»**: зум (наезд 1.1–1.2 работает лучше сильного),
сдвиг в процентах по ширине/высоте и секунды перехода. Широкая панорама плюс медленный сдвиг —
кинематографичный приём ценой одной картинки.

## 4.3. Атмосфера: погода и мастерская спецэффектов

**Встроенные слои** (дождь, снег, туман, пепел) выбираются в поле «Слой» у
погоды — движок рисует их сам, без файлов.

**Мастерская спецэффектов** (вкладка «Механики → Мастерская спецэффектов») —
слои атмосферы из вашей картинки-«частицы». Одна частица — маленький PNG
с прозрачным фоном: капля, листочек, искра, снежинка, мошка. Движок «поливает»
этими частицами экран со следующими настройками:

- количество и размеры частиц;
- скорость по вертикали (вниз — дождь, вверх — дым/искры) и по горизонтали
  (дрейф листопада влево/вправо);
- вращение, непрозрачность и размытие (размытие придаёт даже простой частице
  вид тумана!);
- наложение «свет» — частицы светятся поверх картинки (искры костра);
- зацикленность (возрождаются ли за краем).

Созданный слой сразу появляется в выпадающем списке «Слой» у погоды. То есть
у каждой погоды кампании может быть свой наряд; по умолчанию встроенные слои (rain/snow/fog/ash) доступны без реестра.

**Влияние на игру.** У слоя погоды можно указать боевые эффекты: штраф
к навыкам, ограничение дальности, статус всем бойцам при бое в такую погоду.
Смена времени суток оформляется рядом: у дня и ночи — свои
состояния сцен и звуковые слои.

## 4.4. Тема интерфейса

Раздел «Проект → Оформление» собирает лицо интерфейса кампании:

- **Профиль** — один из готовых художественных наборов (палитра, шрифты,
  атмосферный эффект). Меняет только оформление, не механику.
- **Токены поверхностей** — доп. настройка цвета панелей, карточек и
  кнопок, колодцев полей и фона журнала. Каждый токен включается отдельной
  галочкой — не нужно настраивать всё сразу.
- **Рамка-«кадр»** — PNG с прозрачной сердцевиной и орнаментом по краям.
  Движок «режет» её на 9 срезов и обрамляет все панели игры, как рамы
  старинной карты. Настройки: толщина среза рамки в пикселях и её видимая ширина.
- **Шрифты** — свои файлы WOFF/WOFF2; роли: основной текст, заголовки,
  «рукописный».
- **Фоны меню и финала** — картинки заставок, затемнение для читаемости,
  «кен-бёрнс» (медленный зум), заглавный арт над именем кампании.
- **Полный CSS мастера** — текстовое поле: свои CSS-правила, применяемые
  только к игре. Сильный инструмент для тех, кто умеет верстать
  (правила пишутся для селекторов внутри `.cf-themed`): отступы страниц,
  обводка кнопок, тени, шрифтовые решения — всё правится здесь. Движок не обещает,
  что внутренние классы не поменяются в обновлениях, поэтому этот слой может
  потребовать подстройки после обновлений движка. Опция задумана как будущая
  премиум-возможность — сейчас доступна всем. Токены и профиль намного
  безопаснее; голый CSS нужен редко.

## 4.5. Большие моменты на экране: баннеры и «открытки»

Иногда сцене нужен явный акцент: «сегодняшний день» или финальное слово
концовки. Для этого в правилах и диалогах есть два эффекта:

**Баннер** (`banner`) — большая надпись поверх мира (не «окно сообщения»).
Настройки: текст (понимает токены), наряд (`глава`, `шёпот`, `заголовок`,
`проклятье`, `записочный`), появление (`всплеск`, `тянуть`, `сбоку`,
`молниеносно`), секунды на экране, положение (верх/центр), цвет.

**«Открытка»** (`postcard`) — иллюстрация на весь экран в рамке, с подписью.
Файл или art. Опция «камера» — пан-зум рисунка, как у слайда катсцены.
Гаснет по таймеру или по клику.

Такие ходы держат визуальную подачу: игра показывает мастерский темп повествования,
а мастер не ищет в коде «экран завершения главы».

## 4.6. Портреты: герой и обитатели мира

**Герой** (вкладка «Создание героя → Портрет героя») имеет три режима:

1. **Галерея** — вы предложили готовые портреты, игрок выбирает карточку.
2. **Сборный облик** — сегменты из реестра мастера: лицо, волосы, одежда.
   Игрок собирает героя как в конструкторе.
3. **Живой кадр** — у каждого портрета/варианта свои кадры под состояния:
   ранен, устал, обычный, а также любой статус из вашего реестра — портрет
   в листе персонажа меняется по ходу игры.

**NPC**: у существа эмоции из реестра кампании (радость, гнев, испуг…) — это
варианты портрета в диалоге. Настроение персонажа на диалог ставят правила
и ветки разговора. У обитателя может быть и облик (вид на сцене)
со состояниями: ранен, устал, без брони — отдельные поля карточки существа.

## 4.7. Шпаргалка по файлам

- Картинки кладите через загрузчик редактора — тогда экспорт соберёт пакет
  с файлами полностью.
- Все ссылки http/https кампании можно «вшить» в пакет при
  экспорте (галочка в окне экспорта `*.chronicle`).
- Большие панорамы раскрываются движением камеры — обязательно используйте.
- Для анимации с чётким ритмом берите спрайт-лист: один файл вместо
  нарезки по отдельным кадрам (см. 4.2).
