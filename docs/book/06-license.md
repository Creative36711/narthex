# Лицензия и авторство

Chronicle Forge — самостоятельное программное обеспечение и самостоятельный текст книги. Название BRP используется для обозначения совместимости и происхождения игровых идей. Коммерческая книга *Basic Roleplaying* не является источником текста или иллюстраций этой книги.

Если конкретная распространяемая работа включает Open Game Content из BRP SRD, издатель должен вставить сюда актуальную атрибуцию и полный лицензионный блок, разделить Product Identity и Open Game Content и выполнить остальные требования открытой лицензии Chaosium. Этот раздел — место для заполнения, а не готовая юридическая атрибуция. До публикации сверьте формулировки с актуальными документами на [официальном сайте BRP SRD](https://brp.chaosium.com/) и проверьте состав включённого контента.

**Шаблон для заполнения после юридической проверки:** «В этой работе используются [точно перечисленные материалы] из BRP System Reference Document, опубликованного Chaosium Inc. под BRP Open Game License. Product Identity: [перечень]. Open Game Content: [перечень]. Лицензионный текст и дополнительные обязательные формулировки: [дословный актуальный текст лицензии]».
