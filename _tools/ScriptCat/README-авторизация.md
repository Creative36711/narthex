# Подключения и Drive Gateway

[Установка](./INSTALL.md) · [Ограничения и восстановление](./PORTABILITY.md)

В едином окне **⚙ Подключения** владелец локально сохраняет токен своей интеграции Notion, URL доверенного Apps Script `/exec`, ключ данного проекта и при необходимости GitHub-токен для чтения приватного репозитория и PR. Наличие GitHub-коннектора Arena не означает наличие GitHub-токена у userscript. Не просите и не публикуйте секреты в чате, Git, отчётах или логах. Пользуйтесь проверенным шлюзом: он получает переданный ключ и полномочия владельца своего Google-аккаунта.

## Новый проект: Drive Gateway 1.6

1. В своём Apps Script создайте проект либо согласованно обновите **свой** существующий шлюз. Скопируйте [drive-gateway.gs](./drive-gateway.gs) в код и [appsscript.json](./appsscript.json) в манифест. Манифест запрашивает широкий доступ к Drive — проверьте владельца аккаунта и код до согласия.
2. В свойствах скрипта задайте `CF_SETUP_PROJECT_ID` = UUID созданного профиля и `CF_SETUP_PROJECT_FOLDER` = его точное имя папки. Запустите `setupProjectGateway()` **один раз**; он создаёт `Arena/<папка>/logs`, `payloads`, регистрацию и отдельный ключ. Перенесите ключ непосредственно из закрытого журнала Apps Script в ScriptCat. Не копируйте общий ключ.
3. Функция не присоединяет уже существующие папки и не перезаписывает зарегистрированный проект. Не повторяйте её вслепую после ошибки: проверьте реестр и папки; ошибка могла оставить частично созданные каталоги.
4. Разверните **новую версию** как веб-приложение, выполняющееся от владельца, с доступом «любой, у кого есть ссылка». Одного сохранения кода недостаточно. Вставьте `/exec` в профиль; `ping` должен вернуть UUID и папку этого профиля. Смена сохранённых доступов требует повторного допуска.

В общей совместимости шлюза необязательные Script Properties `CF_LEGACY_LOG_FOLDER_NAME` и `CF_LEGACY_RUN_LOG_FOLDER_ID` задаются только владельцем при необходимости прежних клиентов. По умолчанию чужое имя/ID не предполагаются, перемещения старой папки нет. Если обновляете используемое развёртывание, заранее проверьте его предыдущую конфигурацию и клиентов; старые папки, ключи и реестр не удаляйте. Перенос локального состояния в новый профиль **не переносит** старые журналы в проектную папку; сохраните ссылки и проверяйте их вручную.

## Что проверяют кнопки

«Проверить всё» проверяет подключения по отдельности. Допуск проекта дополнительно читает схему Notion, роли и ветку GitHub и проверяет `ping` шлюза. Это не проверка полномочий агента, не гарантия доступа к произвольным страницам Notion и не полноценная запись/пилот. Arena предоставляет агентам доступ в соответствии со своими настройками подключения; не предполагайте, что userscript ограничивает его отдельными базами.
