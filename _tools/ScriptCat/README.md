# Relay для ScriptCat

Переносимый userscript **1.6.0** ведёт цикл между Coordinator, исполнителем, независимой приёмкой и владельцем через Arena, Notion, Google Drive и GitHub. Проектные адреса не зашиты: профиль задаёт четыре источника Notion, регламент, репозиторий, базовую ветку и папку Drive. Один профиль — одна активная вкладка.

Устанавливаемый файл — [relay.user.js](./relay.user.js), его создаёт `node build.mjs` из `src/`, если запустить команду из этого каталога. Название userscript изменено: автоматическое обновление старой записи и доступ к её локальному хранилищу **не гарантированы**. Сначала остановите цикл, сохраните резервную копию и прочтите порядок переноса. Установка сама не создаёт базы и не запускает миссию. Не удаляйте старую установку или историю, пока восстановление не проверено.

Для разработчика: из этого каталога `node build.mjs --check` сверяет сборку. `node portability-guard.mjs` дополнительно ожидает `../../docs/scriptcat-update.md` относительно этой папки — при размещении в `_tools` это файл в корне репозитория. При переносе его нужно создать либо адаптировать guard. Команды `npm run scriptcat:*` и `npm run smoke:relay-*` определены в корневом `package.json` исходного проекта и не переносятся вместе с этой папкой. Алиасы отдельных проб не заменяют полный набор тестов.
