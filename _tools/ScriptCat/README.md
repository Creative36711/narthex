# Relay для ScriptCat

Переносимый userscript **1.6.0** ведёт цикл между Coordinator, исполнителем, независимой приёмкой и владельцем через Arena, Notion, Google Drive и GitHub. Проектные адреса не зашиты: профиль задаёт четыре источника Notion, регламент, репозиторий, базовую ветку и папку Drive. Один профиль — одна активная вкладка.

Устанавливаемый файл — [relay.user.js](./relay.user.js), его создаёт `node _tools/ScriptCat/build.mjs` из `src/`. Название изменено: автоматическое обновление старой записи и доступ к её локальному хранилищу **не гарантированы**. Сначала остановите цикл, сохраните резервную копию и прочтите порядок переноса. Установка сама не создаёт базы и не запускает миссию. Не удаляйте старую установку или историю, пока восстановление не проверено.

Для разработчика: `npm run scriptcat:check` сверяет сборку, `npm run scriptcat:portability` проверяет переносимый комплект, а `npm run smoke:relay-answer` и другие `smoke:relay-*` — нейтральные алиасы отдельных проб. Исторические команды оставлены для старых оракулов; алиас не заменяет полный набор тестов.
