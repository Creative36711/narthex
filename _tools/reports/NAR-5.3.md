# NAR-5.3 — state-ui: проверка шва реестра

**Итог:** остановлено на обязательном гейте до создания пака. Для изменения `state-machine` из `planned` в `experimental` недостаточно правки разрешённой строки `docs/contracts/caps.json`: `check:contracts` требует идентичности runtime-реестру в `src/core/caps.ts`, а также требует непустую зарегистрированную пробу для экспериментальной возможности. Синхронизация потребовала бы менять запрещённую зоной карточки строку ядра.

## Находка фазы

- `docs/contracts/caps.json:43`: у `state-machine` сейчас `status: "planned"`, `probe: null`.
- `src/core/caps.ts:32`: та же запись runtime-реестра; проверка контрактов сравнивает `id/title/pack/status/since/enables/probe` один-к-одному (`scripts/contracts-check.mts:70–87`).
- В той же проверке экспериментальный статус требует строковый `probe`, существующий в `package.json` (`scripts/contracts-check.mts:89+` и проверка метаданных/скриптов). Поэтому разрешённая правка только статуса в docs-контракте не проходит гейт; согласованная правка потребовала бы как минимум синхронизировать статус и пробу в `src/core/caps.ts`, что прямо запрещено инвариантом этой карточки.

**Находка:** ядро требует строки реестра — `src/core/caps.ts:32` (status `planned` → `experimental` и имя пробы; поле `probe` в текущей записи равно `null`). Ядро и статус контракта не изменялись.

## Проверки

1. `npm ci` — **rc=0**; зависимости установлены локально, lock-файл не менялся.
2. `npm run check:contracts` на исходном состоянии — **rc=0**. В составе команды прошли `check:packs` (3 установленных манифеста) и `check:pack-boundary` (37 файлов ядра, без нарушений), а также остальные включённые контракты и смоуки.
3. Диагностическая проверка без сохранения изменений: временно менялся только статус строки `state-machine` в `docs/contracts/caps.json`, запускался `npm exec tsx scripts/contracts-check.mts`, затем исходный файл немедленно восстановлен. Результат проверки — **rc=1**: расхождение `caps.json` с `src/core/caps.ts` и отсутствие назначения/пробы для `state-machine`. Это подтверждает находку; временная правка не осталась в дереве.
4. `npm run probe:state-ui` и отдельные пробы нового пака **не запускались**: из-за обязательного блокирующего расхождения пак и скрипт пробы не создавались. Реальный проигрыватель `public/ai/cf-play.mjs` не изменялся и не подменялся моками.
5. Проверка финального diff — только этот отчёт; `src/core/**` не изменён.

## Состав пака / шов

Пак `packs/state-ui/**` не создавался: проверка остановлена до реализации согласно условию карточки «не расширять ядро». Шов ядра не потребовался для исполнения автомата; препятствие обнаружено раньше — в обязательной синхронизации реестров. Повторное открытие карточки требует решения, допускающего согласование runtime-реестра, статуса и зарегистрированной пробы.
