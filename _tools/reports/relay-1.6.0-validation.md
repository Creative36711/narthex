# Relay 1.6.0: проверка и открытые вопросы

Дата: 2026-11-02. Основание: владелец разрешил пакет изменений идентичности, привязки миссий, подготовки ADR и переносимости, но исключил усиление доступа и достоверности ролей. Эта запись не меняет исторические ADR и оракулы проекта.

## Что меняется и почему

- Результаты с отсутствующим или чужим ID не перепривязываются к текущему ходу. Ожидание сохраняется, сообщения по возможности архивируются локально; при недоступности архива необходимо сохранить чат вручную.
- Карточки связываются с UUID миссии, перед выдачей проверяются необходимые поля и зависимости. Миграция предусматривает предпросмотр всех строк, запрет неоднозначных записей и повторную сверку. Notion не предоставляет атомарную блокировку: параллельные внешние изменения и частичное применение остаются риском.
- Карточная приёмка не закрывает миссию. Источник окончательного вердикта — приёмка по полному миссионному оракулу. Быстрые проверки не заменяют обязательные финальные; актуальные правила и инструкция передачи — в `../ScriptCat/CONTRACTS.md`.
- Смена имени userscript может привести к новой установке и отдельному локальному хранилищу; успешный перенос не заявляется. Порядок резервирования и ручной проверки описан в `../ScriptCat/INSTALL.md` и `../ScriptCat/PORTABILITY.md`.

## Локальные свидетельства

- Сгенерированный userscript: `_tools/ScriptCat/relay.user.js`, SHA-256 `38e1be463db3fd20a751119714ed24bad89161ed0f95b71d5ba345312e89aea1`.
- `npm run scriptcat:check`, `npm run scriptcat:portability`: успешно.
- Все 85 файлов `_tools/ScriptCat/tests/*.mjs` и `regression-tests/*.mjs`: успешно на Node 22.22.3. Это локальные тесты и модели; проверка SHA исходного текста ADR также имеет положительные и отрицательные фикстуры.
- Оба сценария `_tools/ScriptCat/browser-tests/{connections,profiles}.mjs` выполнены на Chromium с моками и заблокированными внешними запросами. Они не проверяют работающие сервисы.
- `npm run check:brand`, `npm run check:brand:probes`: успешно. `npm audit --audit-level=high`: 0 уязвимостей.
- Комбинированный запуск проверки миссии и её smoke-команд превысил локальный лимит ожидания; окончательный результат второй команды не получен. Его нельзя считать успешным. Прежние проверки других коммитов не доказывают этот выпуск.

## Исторические ADR

Страницы обратной связи [visible-error](https://app.notion.com/p/docs-decisions-STAB-1-17-visible-error-md-40b6f0cf570581b4be03e34e7c4c5f29) и [gateway-normalizer](https://app.notion.com/p/docs-decisions-STAB-1-17-gateway-normalizer-md-40b6f0cf570581efafa0c28d788b6c5e) дополнены постановкой для Warden, вариантами, ссылкой на неизменяемый исходник и полным исходным текстом. Соответствующие Git blob SHA: `26118655df8db04b3a646315f33f228c770e038c` и `210ea2da53d5f43b2c9a5556d6f756c4b1a2f861`. Запись Notion подтвердилась; ответ чтения больших блоков был усечён коннектором, поэтому независимая побайтовая сверка серверных блоков не подтверждена. Повторно не добавлять их без проверки.

На последней проверке обе строки — «Ждёт», поле ответа пустое. Реального решения Warden нет; default не является решением. Статусы исходных ADR и оракулы не менялись. Перед будущей отправкой ADR приёмке скрипт перечитывает страницу и проверяет Git blob SHA; реальный вызов Warden этой проверкой пока не подтверждён.

## Живой пилот — не выполнен

Изолированный проход через живые Arena, Notion, Drive и GitHub не проводился: в этой среде нет авторизованной пользовательской вкладки Arena/ScriptCat и настроенных для теста изолированных ресурсов. Боевые миссии и работающие циклы не запускались. Мок-тесты выше не являются доказательством живого прохода.

Для продолжения владельцу или агенту с доступом к доверенной вкладке нужны отдельные тестовые базы Notion, проектный Gateway/папка Drive, тестовый репозиторий и агенты Arena; порядок и запись свидетельств описаны в `../ScriptCat/INSTALL.md` и `../ScriptCat/TEAM-PLAYBOOK.md`. После согласования записей необходимо проверить карточку, ответ Warden с ID, отдельный вердикт миссии, намеренно неверные ID и восстановление, сохранив ссылки и SHA без секретов.
