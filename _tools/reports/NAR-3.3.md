## Предлагаемый выбор

Предложен путь из ТЗ: добавить ровно один стартовый ID `fmv-crossing` в
поставочный реестр и сохранить пустой реестр отдельной smoke-фикстурой. Игрок
увидит «Перекрёсток огней» в обычном меню; запуск не требует консоли, query
параметров или ручной установки. Проект остаётся помеченным `[DEV]`; ADR
предлагает узкое исключение только для этого ID. До ответа Мастера и смены
`proposed` на `accepted` ни реестр, ни guard менять нельзя.

### Варианты

| Вариант | Что получает игрок | Что ломается / риск | Цена |
|---|---|---|---|
| Оставить как есть (default) | Пустой список и экран «Кампаний пока нет» | Не выполнено намерение карточки: в поставке нет играбельного проекта | Ничего не менять; стартовый проект остаётся отдельной нерешённой задачей |
| `fmv-crossing` в штатном реестре (предложение) | Готовый FMV-проект из обычного меню, запускаемый стандартной кнопкой | `smoke:no-campaign` сейчас требует пустой поставочный индекс; `check:dev-campaigns` отклоняет `[DEV]` в реестре | Разрешить один ID через принятый ADR, изолировать `[]` в smoke и добавить проверку старта |
| Явный выбор проекта при запуске | Отдельный экран, где игрок выбирает проект | Дополнительное состояние/переход; пустой сценарий всё равно надо проверять отдельно | Новый UI-путь и новые проверки выбора, пустого списка и возврата |

Явный экран выбора отклонён в предложении: меню уже выбирает кампанию из
реестра, а новый экран добавляет состояние без необходимости. Вопрос Мастеру
оставляет `fmv-crossing` как предлагаемое решение и включает `Оставить как есть`
как default.
