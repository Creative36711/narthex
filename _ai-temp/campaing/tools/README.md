# Инструменты кампании (`tools/`)

Диагностические скрипты мастера. Они не входят в движок и не участвуют в
игровом времени — только проверки данных перед публикацией.

## Зависимости

- **Python 3.10+** и пакеты: `pip install -r tools/requirements.txt`
  (jsonschema — валидация по схеме; pillow — аудит альфа-канала PNG).
- **Node.js 18+** для ink-скриптов: `npm install inkjs` (нужен для
  `ink_check.cjs` и `route_ink.cjs`; оба — CommonJS, поэтому расширение .cjs).

## Что есть что

| Скрипт | Назначение | Границы применимости |
| --- | --- | --- |
| `validate.py` | Структурная валидация модулей кампании по `__chronicle_ai__/campaign.schema.json`, наличие файлов и медиа-ссылок, аудит PNG-прозрачности спрайтов/фигурок/титульной картинки, срез глав. | Медиа-блок проверяет **упомянутые в данных ссылки**, не файлы на диске; разница «на диске vs в ссылках» — легальные запасные файлы, удалять не принято (политика без лимитов размера). |
| `reach_audit.py` | Строковая эвристика «что определено, но никем не используется»: предметы без выдачи, кодекс без unlock, manual-правила без вызова, узлы ink без перехода, стадии квестов. | Эвристика по подстрокам id, не симулятор прохождения: возможны ложные срабатывания в обе стороны. Проза `design_doc` из выборки исключена. |
| `ink_check.cjs` | Компиляция всех `.ink` через inkjs; код выхода 1 при ошибках. | Игнорирует предупреждения про EXTERNAL (они вызоваются движком). |
| `route_ink.cjs`, `route_sim.py`, `routes.py` | Попытка автопрохождения: выбор вариантов диалога попеременным перебором + грубая топология. | Экспериментальная оценка «маршрут раскрывается», не доказательство проходимости. |
| `combat_sim.py` | Грубая симуляция боёв на стойкость. | Не учитывает тактику игрока. |
| `flag_audit.py`, `dlg_sync_check.py`, `voice_audit.py`, `voice_map.py`, `economy_audit.py`, `edit_helpers.py`, `pack.py` | Служебные одноразовые проверки и помощники конкретных итераций. | См. заголовок каждого файла. |

## Политика размеров и «осиротевших» файлов

Решением 2026-10 движок **не накладывает ограничений размера** пакета и не
удаляет файлы без ссылок: сжатие/оптимизация потерь бы и риск порчи ручной
работы. Эти скрипты проверяют целостность ссылок, а не дисциплинируют диск.
