# Шёпот в шестернях

Кампания для **Chronicle Forge**: тёмное техно-фэнтези с детективом и выживанием,
рассчитанная на 5–7 часов игры. Готовый пакет лежит в архиве
`whisper-in-gears.chronicle` (Campaign Package: `campaign.json`, `world.json`,
`manifest.json`, модули и медиа).

- **Завязка:** в литейном городе-крепости Котёл три недели идёт «тихий мор» —
  люди умирают без крови и без масла, с латунными вставками в позвонках.
  Герой — вольный работник Цеха, которого Курия поднимает на четвёртое тело.
- **Что внутри:** 4 главы, 16 сцен, 11 локаций (десятая — скрытая, глубинное зало),
  14 говорящих НПС и 4 бойца, 7 квестов, 7 концовок, 3 таблицы встреч, 4 арены,
  6 рецептов, 12 записей кодекса, 66 предметов и пропов, 14 ink-диалогов.
- **Механики:** расследование по флагам, проверки навыков, крафт (линза —
  обязательный сюжетный шаг), карантин и вода как ресурсы, ночные патрули
  и погони, четыре взаимоисключающих финала вокруг живого сердца города.

## Репозиторий

| Путь | Что это |
| --- | --- |
| `whisper-in-gears.chronicle` | собранный архив кампании (результат) |
| `package/` | распакованный Campaign Package (генерируется, в git не хранится) |
| `tools/` | генераторы и проверки кампании на Python |
| `__chronicle_ai__/` | инструкции Chronicle Forge (в архив не попадают) |

## Сборка и проверки

```bash
cd tools
python3 make_media.py   # процедурная отрисовка портретов и фонов (ImageMagick)
python3 build.py        # сборка package/ + валидация по campaign.schema.json
python3 check.py        # перекрёстные ссылки: id, флаги, медиа, ink
node /tmp/inkcheck.js   # компиляция ink (inkjs)
```

Архив собирается из распакованного пакета:

```bash
cd package && zip -r -X ../whisper-in-gears.chronicle .
```

## Медиа и права

Все изображения (портреты НПС, бойцы, фоны меню и концовок, эмблема)
нарисованы процедурно скриптом `tools/make_media.py` из примитивов ImageMagick;
сторонние материалы не использовались, звук синтезируется движком (zzfx).
Авторство кампании зафиксировано в `campaign.attribution`.
