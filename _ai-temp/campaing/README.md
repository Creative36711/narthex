# Каркас: Медное сердце

Кампания Chronicle Forge — тёмное техно-фэнтези с расследованием и выживанием,
5–7 часов игры. Готовый пакет: **[`karkas_mednoe_serdce.chronicle`](karkas_mednoe_serdce.chronicle)**
(архив формата Campaign Package, ~900 КБ).

## О чём игра

Город-завод Каркас, 137-й год Пепла. Двенадцать лет назад Сердце — машина, вокруг
которой построен город, — остановилось. Теперь кто-то вскрывает грудь тем, кто
спускался к Сердцу, и вынимает медные сердца. Герой — дознаватель Надзора с таким
же сердцем в груди: улики, показания, дедлайны, еда, вода, тепло и воздух по
талонам. В финале придётся решать не «кто убийца», а что делать с Сердцем.

## Состав пакета

| Раздел | Что внутри |
| --- | --- |
| `campaign.json` | метаданные, реестры (навыки, флаги, потребности, статусы, погода, фракции, цены), создание героя, 9 концовок, прогрессия, музыка и звуки, `design_doc` |
| `world.json` | 1 регион, 8 локаций (Поддон скрыт до спуска), карта-примитивы |
| `scenes/` | 18 сцен, у каждой состояния, слоты, навигация и взаимодействия |
| `entities/` | 68 сущностей: 12 персонажей, 5 противников, 51 предмет (включая сценовые объекты) |
| `rules/` | 30 правил (пролог, улики, дедлайны убийств, погода, погоня, нужды, финалы) + `encounters.json` с тремя таблицами встреч |
| `quests/` | 6 квестов: сюжет «Медное сердце» (8 стадий) и пять побочных |
| `arenas/` | 8 гексагональных арен |
| `cutscenes/` | 7 катсцен (пролог, второе убийство, спуск, Сердце, печать, ток, поверхность) |
| `recipes/` | 4 рецепта: фильтр, болт, починка маски, огранка линзы |
| `codex/` | 14 записей кодекса (город, Цех, Спуск, твари, Предтечи) |
| `dialogues/` | 11 диалогов в формате ink |
| `assets/img/` | портреты 8 ключевых персонажей, фон меню, 5 жетонов тварей |

Медиа: сцены, катсцены и карта нарисованы процедурно (слои ArtDoc), музыка
описана документами MusicDoc, звуки — массивами zzfx: движок синтезирует их сам,
поэтому в пакете нет ни одного аудиофайла, а растровые файлы — только портреты и
фоны.

## Сборка

```bash
python3 tools/build.py       # пересобрать package/ и .chronicle
python3 tools/validate.py package   # проверка по схеме и внутренним связям
python3 tools/pngart.py assets/img  # перерисовать жетоны тварей
```

`tools/` — генераторы контента (`content_*.py`), процедурная графика (`artlib.py`),
рендер жетонов (`pngart.py`) и самописный валидатор (`validate.py`,
`jsonschema_mini.py` — подмножество JSON Schema без внешних зависимостей).
`__chronicle_ai__/` — документация движка, в архив не входит.

Дизайн-документ кампании лежит в `tools/design_doc.md` и продублирован в поле
`campaign.design_doc` внутри пакета.
