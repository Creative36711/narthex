# Правки раунда 27 (4 октября 2026)

Что сделано с пакетом «Шестерни и пепел» и с движком по вашему списку 1–9.
Пакет кампании и релизный архив можно импортировать заново — описанные ниже
дефекты в них уже устранены.

## В пакете кампании

- **Служебная строка «true» в диалогах (п.6).** В 10 диалогах 41 выбор был
  записан как `+ [Текст] { условие }` — часть сборок inkjs печатает значение
  условия отдельной репликой. Условие перенесено перед квадратные скобки:
  `+ { условие } [Текст]`. Исправлены и `campaign_package/dialogues/*.ink`,
  и архив `release/shesterni-i-pepel.chronicle`.
- **Аудит кампании** теперь сам находит такие выборы и подписи реестров вида
  «crime_intrusion=Проникновение…»: файлы пакета проходят проверку без
  предупреждений (errors 0, warnings 0).

## В движке

1. «Вышла (дата, ISO)» — календарный выбор даты (`type=date`); похожие
   текстовые поля редактора больше не требуют парсерных форматов.
2. Реестры (страсти, приверженности, преступления, ценовые события, черты,
   категории навыков) редактируются строками «название + код»; правило засады
   выбирается из списка правил; модификаторы черты и сдвиги навыков погоды —
   строки «что — прибавка»; требования черты — конструктор условий.
3. Ряд «N × dN + мод» в редакторе компактный (селекты больше не растягиваются
   на всю ширину).
4. Категории навыков заполняются человекопонятно (см. 2).
5. У потребностей появилось поле описания (подсказка игроку).
6. Защита движка: строки-литералы (`true`, `false`, `null`, `nan`) не попадают
   в диалог, даже если их напечатает inkjs; в чемодане ИИ-агента закреплены
   безопасные конструкции Ink.
7. Ремонт сохранения больше не отбирает законные данные: шаблонное снаряжение
   (предмет есть в кампании, но не в инвентаре) остаётся надетым, личные
   отношения с NPC сохраняются, а чистятся только ссылки на то, чего в
   кампании действительно нет.
8. Мелкие недоработки интерфейса из скриншотов: дубль «Локация — Локация —
   День» в заголовке сцены убран, эмодзи и нативные подсказки вычищены из
   интерфейса.
9. По разделу «Что пока нельзя сделать в движке»: из реплики теперь работают
   `skill_check` (честные 1/0 — ветвление успех/провал), `set_entity_state`
   (смена облика/эмоции) и `open_trade` (торговля); всё это документировано в
   гайде.
