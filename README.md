# Chronicle Forge

**Редактор и рантайм тактических визуальных новелл.** Один проект — два режима:
**Player Mode** (игра: сцены, диалоги, выживание, гекс-бои, рогалик-луп) и
**Editor Mode** (визуальный редактор кампаний: без кода и без ручных id).
Контент полностью отделён от движка и распространяется пакетами кампаний
(`.chronicle` / каталог `public/campaigns/<id>/`).

**Статус:** Фазы 0–4 завершены, семь итераций по фидбеку плейтеста отработаны.
Впереди Фаза 5 (полировка: PixiJS-рендер боя, звук, анимации).

Подробное устройство проекта — в **[ARCHITECTURE.md](./ARCHITECTURE.md)**.

## Возможности

### Игра (Player Mode)

- **Сцены и мир** — сцены со состояниями (день/ночь, флаги), слоты персонажей и
  предметов, зоны навигации; карта региона и путешествия со стоимостью в тиках,
  случайные встречи на дорогах.
- **Время и выживание** — тики, время суток, потребности с условной убылью и
  восстановлением (голод, жажда, энергия; в демо ещё «Тепло»: мёрзнем ночью на
  улице без плаща, отогреваемся у очага таверны).
- **Живые НПС** — расписания по часам (стражник днём у ворот, ночью в казарме),
  «особые места по событиям» (пока активен флаг — персонаж в другом месте),
  портреты-настроения в диалогах.
- **Диалоги** — Ink-рантайм (inkjs) с проверками навыков, условными репликами,
  эффектами (предметы, флаги, квесты, торговля, бой) и «одноразовыми» вопросами.
- **BRP d100** — проверки навыков (критический/особый/успех/провал/крит-провал),
  производные HP/MP, рост навыков через «галочки» опыта и броски во сне.
- **Тактический бой на гексах** — инициатива по DEX, зона движения (Дейкстра),
  атака/уклонение/парирование, криты, предметы в бою, AI врагов и напарников (A*),
  лут; атака завершает ход автоматически, «Пропустить ход» — для хода без атаки.
- **Квесты, фракции, торговля** — стадии с переходами, журнал, репутация
  −100…+100 (влияет на цены и ветки диалогов; служебные фракции скрыты от игрока),
  торговцы с прилавком, запасами и скупкой.
- **Напарники** — присоединяются по сюжету, воюют на стороне игрока, гибнут навсегда.
- **Рогалик-луп** — permadeath, автосейв стирается при смерти, новый забег — новый seed.
- **Обучение** — встроенная справка «Как играть» + одноразовые интерактивные
  подсказки по ходу игры; кнопка «🎓 Обучение заново» в меню и в справке.

### Редактор (Editor Mode)

Открывается кнопкой «🛠 Редактор» в главном меню (или `/#editor`). Принципы:
**никаких ручных id** (генерируются из названий), **всё ссылочное — выпадающими
списками**, **весь интерфейс по-русски**, изображения загружаются с компьютера.

- **Кампания** — реестры: потребности (с конструктором условий убывания и
  восстановления), навыки, флаги (русские названия + описания), фракции
  (со «скрытыми»), категории предметов, типы слотов сцены, валюты.
- **Мир** — карта, регионы и локации, связи путешествий.
- **Сцены (Konva)** — слоты и зоны навигации перетаскиванием; типы слотов
  фильтруют, кого можно поставить; условия видимости (время суток, флаги).
- **Сущности** — формы НПС (характеристики, навыки, снаряжение предметами,
  дроп, торговля, расписание, особые места по событиям, портреты-состояния) и
  предметов (категория задаёт поля; структурный ввод урона N×dX+бонус).
- **Правила** — визуальный конструктор условий и эффектов с русскими сводками.
- **Квесты** — стадии, переходы, журнальные записи, награды, финалы.
- **Диалоги** — визуальный конструктор (узлы, реплики, условия, проверки навыков
  с ветками успех/провал, «иначе»-блоки); `.ink` генерируется автоматически,
  вручную его писать не нужно.
- **Арены** — раскраска гекс-сетки кистями (стены, сложная местность, спавны).
- **Кампании** — создание, удаление, экспорт/импорт `.chronicle` (zip),
  сохранение на диск в dev-режиме, «Плейтест» в соседней вкладке.
- Откат (Ctrl+Z) с честным счётчиком «несохранено», единые стилизованные модалки
  вместо браузерных окон.

## Запуск

```bash
npm ci            # точные версии из package-lock.json
npm run dev       # игра + редактор: http://localhost:5173 (редактор: /#editor)
npm run build     # прод-сборка в dist/
npm run preview   # прогон прод-сборки
```

Десктоп (Tauri v2, нужен Rust-тулчейн — https://rustup.rs; на Linux ещё webkit2gtk/gtk):

```bash
npm run tauri dev
npm run tauri build
```

Примечание: сохранение из редактора на диск работает в dev-режиме vite
(эндпоинты `/__editor/save`, `/__editor/delete`). В прод-сборке и Tauri пока
используйте экспорт `.chronicle`.

### Проверки (смоук-тесты)

Нужен запущенный dev-сервер на `:5173`:

```bash
npx tsx scripts/feedback-smoke.mts    # …и feedback2 … feedback7
npx tsx scripts/regen-ink.mts         # перегенерация .ink из документов конструктора
```

Семь смоуков покрывают движок (бой, диалоги, квесты, потребности, расписания),
редакторский стор и генерацию Ink — всё headless, без браузера.

## Демо-кампания «Пепел Каэрдена»

Долину душит банда Серого Йорека. У героя — меч, двадцать марок серебра и десять
дней до штурма города.

- 10 сцен: ворота (2), рынок, таверна, храм, казармы, лесная опушка, шахта (2), лагерь банды.
- НПС: страж Алдрик (может стать напарником), торговец Бран, хозяйка таверны Маэва,
  отец Корвин (лечение и квест реликвии), осведомительница Лена (тайный путь), Серый Йорек.
- Выживание: еда, вода, сон, ночной холод (шерстяной плащ или очаг таверны).
- Квесты: «Угроза с холмов» (главный: убеждение / взятка / бой — два финала),
  «Крысы в подвале», «Реликвия отца Корвина», «Тайный путь».
- Таймлайн давления: день 6 — слухи о налёте, день 7 — налёт на рынок,
  день 10 — штурм ворот (финальный бой).

## Структура

```
src/
  shared/   — типы формата кампании, общие модалки, словарь навыков
  core/     — движок: состояние, BRP, время, условия/эффекты, бой, Ink, PRNG, сейвы
  player/   — Player Mode: React-экраны, HUD, панели, справка, подсказки
  editor/   — Editor Mode: стор, конструкторы, Konva-сцены, Monaco, .chronicle
scripts/    — headless смоук-тесты и регенерация ink
src-tauri/  — Tauri v2 оболочка (десктоп)
public/campaigns/ash-of-caerden/ — демо-кампания (Campaign Package)
```

Подробности — в [ARCHITECTURE.md](./ARCHITECTURE.md).

## Технологии

React + TypeScript + Vite · inkjs (Ink runtime + компилятор) · seedrandom ·
Konva/react-konva (редактор сцен) · Monaco (JSON/ink, в бандле — без CDN) ·
JSZip (`.chronicle`) · Tauri v2 (десктоп) · далее по ТЗ: Howler (звук, Фаза 5).

Гекс-логика и рендер боя — свои (odd-r/кубические координаты, A*, SVG-оверлей):
логика полностью отделена от рендера и тестируется headless; переход на
PixiJS предусмотрен, когда понадобятся анимации и большие карты.
