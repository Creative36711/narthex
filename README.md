# Chronicle Forge

Редактор и рантайм тактических визуальных новелл. Реализация по ТЗ «Chronicle Forge».

**Текущий статус: Фаза 4 завершена + две итерации по фидбеку плейтеста. Осталась Фаза 5 (полировка).**

## Итерация по фидбеку №7 (4 пункта)

1. **Условные потребности.** У потребности появились «Условия убывания»: она убывает, только когда выполнены все условия (время суток, флаг, локация, есть/нет предмета, надет/не надет). Конструктор — в «Кампания → Потребности», по-русски, без JSON.
2. **Скрытые фракции.** Галочка «Скрытая (не показывать в игре)» для служебных фракций («Дикие твари»): игрок их не видит в панели отношений.
3. **Потребности закрывают не только предметы.** У потребности есть «Восстановление за тик» со своими условиями: тёплое помещение греет само. Демо: потребность «Тепло» — убывает вечером и ночью на улице без шерстяного плаща (продаётся у Брана), у очага «Дубового щита» восстанавливается.
4. **Обучение возвращено под контроль.** Интерактивные подсказки (первый бой, проверки в диалогах, рост навыков) — одноразовые, поэтому «исчезали» после первого просмотра. В главном меню появилась кнопка «🎓 Обучение заново», включающая их снова. Проверка: `npx tsx scripts/feedback7-smoke.mts`.

## Итерация по фидбеку №6 (5 пунктов)

1. **Без «авто».** «Тип в слотах сцены» всегда показывает конкретный тип (Персонаж, Предмет…), слово «авто» убрано из редактора. Неиспользуемый встроенный тип «Мебель» удалён — встроенных типов четыре, свои добавляются в реестре.
2. **Особые места по событиям.** У НПС появилась секция «Особые места (по событиям)»: пока флаг установлен (и, опционально, пока другой НЕ установлен) — персонаж находится в выбранной сцене и слоте, расписание не действует. Демо: пока ходят «Слухи о налёте», Лена дежурит в тёмном углу таверны круглосуточно; после зачистки лагеря возвращается к обычному распорядку.
3. **Удаление кампаний.** Кнопка «🗑 Удалить» в шапке редактора и корзинка в списке кампаний главного меню: подтверждение, стирание файлов с диска, обновление реестра; последнюю кампанию удалить нельзя.
4–5. **Чёрный экран при создании/смене кампании починен.** Причина: рендер успевал обратиться к новому стору до загрузки файлов (`manifest`/`meta` ещё не было). Готовность теперь привязана к конкретному стору, а до загрузки стор отдаёт безопасные пустые значения. Проверка: `npx tsx scripts/feedback6-smoke.mts`.

## Итерация по фидбеку №5 (5 пунктов)

1. **Атака завершает ход сама.** Больше не нужно жать «Завершить ход» после каждой атаки; кнопка переименована в «Пропустить ход» и нужна лишь для хода без атаки. Справка обновлена.
2. **Типы слотов.** Встроенные типы показаны в реестре и не удаляются; список «Кто/что стоит в слоте» фильтруется по допустимым типам слота (в бочку с водой больше не поставить стражника). У слотов появились названия («Пост у ворот», «Стойка Маэвы»).
3. **Тип в слотах — у каждой сущности.** Поле «Тип в слотах сцены» в карточках НПС и предметов (умное умолчание: НПС — персонаж, контейнер — контейнер, прочее — предмет; крыса — животное).
4. **Расписание НПС — видно и редактируется.** Присутствие стражника/торговца по часам никогда не было хардкодом (это `schedule` в данных НПС), но пряталось в «Расширенном JSON». Теперь в форме НПС есть секция «Расписание»: «с 6 до 18 — Ворота, Пост у ворот», сцены и слоты — выпадающими списками.
5. **Создание кампании больше не ломает редактор.** Причина: vite полностью перезагружал страницу при каждой записи в `public/campaigns` (создание кампании обрывалось на середине, экран пустел). Теперь файлы кампаний отдаёт собственный middleware с диска, vite за ними не следит; ошибки загрузки — понятные, по-русски, а экран ошибки предлагает «Попробовать снова», открыть другую кампанию или выйти в меню. Проверка: `npx tsx scripts/feedback5-smoke.mts`.

## Итерация по фидбеку №4 (12 пунктов)

1. **Сообщение победы — сразу.** Эффекты `on_victory` (сообщения, флаги, отношение) применяются в момент победы, ещё на экране боя, до «Продолжить»; смена экрана (диалог, телепорт, финал) — после закрытия.
2. **Никаких браузерных окон.** Единые стилизованные модалки (`src/shared/modals.tsx`): подтверждения, сообщения и ввод текста — и в редакторе, и в игре (выход в меню, выброс предмета, удаления и т.д.).
3. **Свои типы слотов.** Реестр «Кампания → Типы слотов сцены»: к встроенным (персонаж, предмет, контейнер, мебель, животное) мастер добавляет свои — «робот», «дух» и т.п.
4. **Флаги по-русски.** Реестр «Кампания → Флаги» (название + для чего нужен); во всех местах выбора флага — выпадающий список с русскими названиями и пунктом «Создать новый флаг». Все 25 флагов демо-кампании описаны.
5. **«Откат» и счётчик «несохранено».** Редактор сравнивает файлы с состоянием на диске: откат к сохранённому состоянию обнуляет счётчик.
6. **Реестр навыков.** Добавлены «Дубины» (club) и «Щиты» (shield) — навыки НПС больше не выпадают из реестра.
7. **НПС снаряжены.** Дубина, копьё стражи, клеймора, стёганка, кольчужная рубаха — настоящие предметы в снаряжении бандита, стражника, Йорека и Алдрика (у крысы — природный укус). У НПС появилась секция «Торговля»: прилавок, цены, запас, скупка.
8. **Цены.** Подпись просто «Цена» (без названия валюты — сеттинги любые); валюта стоит 1, у пайка стражи появилась цена.
9. **Урон конструктором.** Вместо свободного текста «1d6+1» — структурный ввод: количество × кубик + модификатор.
10. **Проверено: засада в лесу — правило** (`rule_forest_ambush`, условие «игрок входит в Тёмный лес»), хардкода контента в движке нет.
11. **Стадии квестов в сводках по-русски.** «Журнал: Крысы в подвале, Крысы перебиты» вместо `completed`.
12. **Диалоги полностью в конструкторе.** Формат конструктора v2: условия (флаги, предметы, отношение, квесты, отряд, здоровье), проверки навыков с ветками успех/провал и переменной сложностью, условные блоки реплик с «иначе». Все 6 демо-диалогов конвертированы в визуальный формат (`.dlg.json`), у диалогов человеческие названия, слово «ink» из интерфейса убрано, узел для «Начать диалог» выбирается из списка. Проверка: `npx tsx scripts/feedback4-smoke.mts`, перегенерация ink: `npx tsx scripts/regen-ink.mts`.

## Итерация по фидбеку №3 (14 пунктов)

1. **Выход в меню из игры** — кнопка ⏻ в HUD (с подтверждением; прогресс сохраняется автоматически).
2. **Провал проверок запоминается** — отказ Алдрика делиться едой ставит флаг `aldric_ration_refused`: переспросить в новом разговоре нельзя. Остальные диалоги проверены (у Брана флаг ставился всегда, у Йорека провал ведёт в бой).
3. **Уведомления во время боя** — оверлей `show_message`/квестовых сообщений больше не прячется, пока идёт бой (z-index выше арены).
4. **Перевод навыков в панели «Герой»** — устаревший локальный словарь заменён на `engine.skillLabel()` (реестр кампании + встроенные названия): brawl → «Кулачный бой».
5. **Инвентарь не растягивается** — кнопка выбрасывания стала компактной иконкой 🗑.
6. **Никаких браузерных prompt()** — стилизованный модал `askText()` (`src/editor/prompt.tsx`), заменены все 9 мест: регионы и локации мира, новая кампания, новые элементы, потребности/фракции/навыки, стадии квестов, узлы диалогов.
7. **Алфавитный порядок** — все выпадающие списки (`store.options`) и списки разделов редактора отсортированы по-русски.
8. **Категории предметов** — реестр в «Кампания → Категории предметов»: категория задаёт, что умеет предмет (лечит HP, восстанавливает потребности, оружие, броня). Форма предмета показывает поля по категории; чекбоксы «Это оружие/Это броня» убраны. Починена цена (редактор писал `value.item_silver`, движок читал `value.silver` — теперь оба используют первую валюту кампании). Список сущностей сгруппирован: «Персонажи», затем предметы по категориям.
9. **Форма NPC** — «Броня» убрана из характеристик: отдельное поле «Природная защита» с пояснением (надетая броня даёт очки отдельно); стартовое снаряжение (оружие/броня селектами из подходящих предметов) и инвентарь; таблица дропа (предмет, шанс %, от/до — у гигантской крысы теперь есть дроп); портреты-состояния динамические (+ свои состояния — они же появляются в конструкторе диалогов как «настроение»); отдельное «Изображение в бою» (`token`, бой использует его с фолбэком на портрет); добавлена отсутствовавшая фракция крыс «Дикие твари».
10. **Правила без англицизмов** — «Срабатывает один раз», «Только ручной запуск»; потребность и навык в условиях/эффектах — селекты по реестрам кампании.
11. **Человекочитаемые правила** — сводки условий/эффектов показывают русские названия (локации, сцены, NPC, предметы, фракции); «Время суток» — чипы-мультивыбор периодов; враги/союзники в «Начать бой» и предметы наград — визуальные списки «кто × сколько» вместо JSON.
12. **Квесты упорядочены** — стадии получили русские названия (label), журнальные записи привязаны к стадиям селектом; «Стадия» в условиях/эффектах — селект по стадиям выбранного квеста; «Изменить отношение» — селект «Фракция или NPC».
13. **Пояснение про диалоги-код** — рукописные Ink-диалоги демо открываются с баннером: новые диалоги создаются в визуальном конструкторе без кода.
14. **Главное меню** — список кампаний открывается по кнопке «📚 Кампании» (окном, а не постоянной колонкой); там же импорт пакета `.chronicle` прямо из меню; исправлен чёрный экран после создания кампании (ожидание готовности файлов на dev-сервере + переход в раздел «Кампания»).

Смоук: `npx tsx scripts/feedback3-smoke.mts` (нужен dev-сервер на :5173).

## Итерация по фидбеку №2 (23 пункта)

Игрок:
- диалоги: мягкий контраст реплик, просторная подсказка о проверках, «одноразовые»
  вопросы исчезают до конца разговора и возвращаются в новом (каждый разговор —
  свежая Ink-история; «навсегда» помнится только флагами);
- сообщения «Новый квест …» показываются сразу, поверх диалога — до боя;
  квест «Крысы в подвале» завершается после благодарности Маэвы, а сама Маэва
  первой заговаривает с героем при входе в таверну (правило start_dialogue);
- инвентарь: кнопка «Выбросить», автоописание эффектов предметов («восстанавливает 5 HP»);
- все навыки локализованы (реестр навыков кампании + встроенный словарь);
- экран победы не перекрывает финальный диалог, сейв стирается при любом финале,
  seed убран из экрана итогов, тексты без англицизмов.

Редактор:
- конструктор диалогов: узлы/реплики/ответы формами, условия по флагам, эффекты
  выпадающими списками, автогенерация .ink (hub-паттерн, защита от зависания);
- мир: карта с загрузкой изображения с компьютера, маркеры локаций расставляются
  и перетаскиваются мышью, вложенные регионы (мир → страна → город);
- загрузка изображений «с компьютера» везде (фоны сцен, портреты, арены, предметы, карты);
- id полностью убраны из интерфейса: всё создаётся по названию (транслитерация),
  все ссылки — выпадающие списки с названиями; условия состояний сцены — русским
  конструктором (время суток/флаги); типы слотов по-русски;
- потребности: настройка «что происходит при нуле» (смерть/правило);
- арена привязывается к локации; «⬇ Экспорт» вместо «.chronicle»;
  меню с несколькими кампаниями свёрстано заново.

## Итерация по фидбеку плейтеста

- **Полноэкранный бой** — экран боя занимает всё окно, журнал боя показывается целиком
  с автопрокруткой и подсветкой (раунды/попадания/промахи/смерти); экран поражения
  больше не перекрывается ареной (фикс z-index).
- **Экипировка** — в листе персонажа виден блок «Снаряжение» (оружие в руках / броня);
  в инвентаре — бейдж «✓ надето» и кнопки «Надеть»/«Снять»; бой берёт оружие/броню
  игрока из экипировки (без оружия — кулаки 1d3); потеря предмета снимает его автоматически.
- **Диалоги-хабы** — реплики НПС не накапливаются: после каждого выбора видны только
  новые строки; авторские ремарки (`# action` в ink) выводятся курсивом со значком ✦
  и не влияют на портрет.
- **Порядок квестов** — `set_flag` из диалога сразу прогоняет правила (пока не начался
  бой/торговля): «Крысы в подвале» стартует до боя, а не после.
- **Платформа кампаний** — главное меню показывает список кампаний из
  `public/campaigns/index.json` («Пепел Каэрдена» — встроенная демо-кампания);
  выбор запоминается.
- **Редактор** — создание новой кампании из меню редактора (скаффолд + запись в реестр);
  формы вместо голого JSON для кампании, мира (регионы/локации/дороги) и сущностей
  (предмет/NPC) с fallback «Расширенный JSON»; id генерируются автоматически из названий
  (транслитерация); многошаговый откат (кнопка «↩ Откат» и Ctrl+Z); починена вёрстка
  панели арен (поля больше не вылезают из формы).
- **Справка и обучение** — «❓ Как играть» в главном меню и в HUD (свой текст: d100-проверки,
  рост навыков, бой, потребности, социальные механики, рогалик-луп); интерактивные
  подсказки первых минут: оверлей-туториал в первом бою, плашка при первой проверке
  в диалоге, пояснение роста навыков после первой победы (одноразовые, localStorage).

## Что уже работает

- **Формат кампании (Campaign Package)** — TypeScript-типы и распакованная структура
  (`campaign.json`, `world.json`, `/scenes`, `/entities`, `/rules`, `/dialogues`, `/assets`),
  загрузка по `manifest.json`.
- **Сцены** — состояния (день/ночь по времени суток, флаги), слоты с сущностями,
  зоны навигации между сценами/локациями, тонирование по времени суток.
- **Мир и путешествия** — карта региона, точки локаций, подтверждение стоимости пути в тиках.
- **Система времени** — тики, время суток (утро/день/вечер/ночь), «День 3, 14:00» в HUD.
- **Потребности** — голод/жажда/энергия: убывание за тик, критические пороги,
  эффект при обнулении (смерть или manual-правило, например обморок).
- **Расписания NPC** — Алдрик днём у ворот, вечером в таверне; слоты заполняются динамически.
- **Диалоги — Ink (inkjs)** — компиляция `.ink` при загрузке, теги эмоций (`# emotion: ...`),
  external functions: `has_item`, `add_item`, `remove_item`, `item_count`, `skill_check`,
  `change_need`, `set_flag`, `get_flag`, `advance_time` и др.
- **BRP-ядро** — d100-проверки навыков (critical/hard/success/fail/fumble),
  производные HP/MP, damage bonus, MOV; кости `1d6+1`.
- **Триггеры/эффекты** — декларативные условия (AND/OR/NOT, флаги, время, предметы, переменные)
  и эффекты (диалог, телепорт, предметы, потребности, сообщения, reveal_location…).
- **Инвентарь** — предметы с весом, использование (еда/вода/травы), стакаемость.
- **Рогалик-луп** — permadeath: автосейв (localStorage) удаляется при смерти,
  рестарт пересоздаёт seed PRNG (seedrandom), экран статистики забега.
- **Тактический бой на гексах (Фаза 1)** — арены из ТЗ §3.9 (offset odd-r,
  блокированные гексы, сложная местность ×2, зоны спавна); инициатива по DEX;
  движение (Dijkstra-зона досягаемости), атака по навыку оружия,
  защита уклонением/парированием (повторные −30%), урон = кости + damage bonus − броня,
  криты (макс. урон, игнор брони); базовый AI (A* к ближайшей цели, атака);
  лут-таблицы поверженных; смерть игрока в бою = конец забега.
  Бой запускается эффектом `start_combat` из правил или из Ink через `fire_rule(id)`.
- **Квесты (Фаза 2)** — стадии с переходами по условиям, журнальные записи,
  финалы success/failure, эффекты `start_quest`/`advance_quest`/`journal_update`/`give_reward`,
  вкладка квестов в журнале.
- **Фракции и репутация** — диспозиции −100…+100, `change_disposition`,
  условия `disposition_ge/le`, влияние на цены и ветки диалогов, блок в листе персонажа.
- **Торговля** — NPC-торговцы (`trader`), покупка/продажа, цена зависит от
  репутации и навыка Торговли, вызов из Ink через `open_trade(id)`.
- **Случайные встречи** — таблицы по ТЗ §3.8 (nothing/combat/skill_check/event),
  бросок при путешествии по помеченным маршрутам.
- **Напарники** — `join_party` (из Ink или эффектов), участие в бою на стороне
  игрока под управлением AI, перманентная смерть, HP сохраняется между боями.
- **Рост навыков** — «галочки» опыта за успешные проверки (диалоги, атаки, защиты,
  торговля), броски роста во сне: d100 > навык → +1d6.
- **Груз и перегруз** — вес инвентаря против STR+SIZ; перегруз режет MOV и уклонение в бою.
- **Предметы в бою** — использование расходников (мазь, еда) тратит действие.
- **Полная кампания (Фаза 3)** — новые локации: храм Света (отец Корвин: лечение,
  благословение), казармы (ночёвка Алдрика), заброшенная шахта (скрыта до наводки);
  побочные квесты «Крысы в подвале» (формализован), «Реликвия отца Корвина»
  (шахта, ловушка-самострел через `skill_check_gate`, медальон, награда `change_skill`)
  и «Тайный путь» (Лена в таверне ночью при репутации города ≥20 → лаз в шахте →
  внезапная атака на лагерь: у Йорека меньше охраны, убеждение легче);
  таймлайн давления: день 6 — слухи, день 7 — налёт банды на рынок
  (бой с патрульным стражником в союзниках), день 10 — штурм ворот
  (Йорек + 3 бандита против игрока, трёх стражников и напарников; победа = финал).
- **Временные союзники боя** — поле `allies` эффекта `start_combat`
  (стража города сражается рядом, не входя в партию).
- **Editor Mode (Фаза 4)** — полноценный редактор кампании (кнопка «Редактор»
  в главном меню или `/#editor`):
  - **Сцены (Konva)** — слоты и зоны навигации как перетаскиваемые/масштабируемые
    прямоугольники поверх фона, свойства слотов, состояния сцены;
  - **Арены** — раскраска гекс-сетки кистями: блокированные гексы, сложная
    местность, зоны спавна игрока и врагов;
  - **Правила** — визуальный конструктор: типизированные формы всех условий (21)
    и эффектов (28), вложенные списки (`on_victory`, `skill_check_gate`),
    подсказки id из кампании (datalist);
  - **Квесты** — конструктор стадий: переходы с условиями, эффекты при входе,
    журнальные записи, финалы success/failure;
  - **Диалоги (Monaco)** — редактор `.ink` с подсветкой и проверкой компиляции
    (inkjs) до применения;
  - **Кампания/Мир/Сущности (Monaco)** — JSON-редактор с валидацией;
  - **Сохранение на диск** — в dev-режиме vite файлы пишутся прямо в
    `public/campaigns/<id>/` (эндпоинт `/__editor/save` с защитой пути);
  - **Экспорт/импорт `.chronicle`** — zip Campaign Package со всеми ассетами (JSZip);
  - **Плейтест** — сохранить и открыть игру в соседней вкладке.
- **Tauri-оболочка** — `src-tauri/` (Tauri v2): десктоп-сборка
  `npm run tauri dev` / `npm run tauri build` (требуется Rust-тулчейн).

## Демо-кампания «Пепел Каэрдена» (срез Фазы 0)

Городские ворота (2 сцены), рынок, таверна «Дубовый щит», лесная опушка.
NPC: страж Алдрик (первый квестовый диалог, расписание, проверка Убеждения),
торговец Бран (покупки, проверка Торговли), Маэва (еда, ночлег, слухи).
Выживание: пить из бочки, покупать еду, спать в таверне — иначе смерть от истощения.

Бои: «Крысы в подвале» (лёгкий, по квесту Маэвы, диалог запускает бой)
и засада бандитов на лесной дороге (опасный, при первом входе в лес; с добычей).
Баланс проверен симуляцией (бот-«болванчик»: подвал ~95%, лес ~65% побед).

**Главный квест «Угроза с холмов»** (условие победы кампании):
Алдрик рассказывает о банде → Бран даёт детали и открывает Волчью балку на карте →
в лагере Серого Йорека развилка: убеждение (Persuade, сложно), взятка (100 SM)
или бой (Йорек + бандиты; можно позвать Алдрика в напарники, если репутация
стражи ≥ 10 — её даёт зачистка засады в лесу). Оба финала завершают забег победой,
но по-разному меняют репутацию. Бран — полноценный торговец; на дороге в лес
работает таблица случайных встреч.

## Запуск

```bash
npm install       # или npm ci — точные версии из package-lock.json
npm run dev       # игра + редактор: http://localhost:5173 (редактор: /#editor)
npm run build     # прод-сборка в dist/
npm run preview   # прогон прод-сборки
```

Десктоп (Tauri v2, нужен установленный Rust — https://rustup.rs, а на Linux ещё
webkit2gtk/gtk по докам Tauri):

```bash
npm run tauri dev     # дев-окно поверх vite
npm run tauri build   # установщик/бинарь под текущую ОС
```

Примечание: сохранение из редактора на диск работает в dev-режиме vite
(`/__editor/save`). В прод-сборке и Tauri пока используйте экспорт `.chronicle`.

## Структура

```
src/
  shared/   — типы формата кампании
  core/     — движок: state machine, BRP, время, условия/эффекты, Ink-диалоги, PRNG, сейвы
  player/   — рантайм (Player Mode): React-экраны и HUD
  editor/   — Editor Mode (Фаза 4): Konva-сцены, Monaco, конструкторы, .chronicle
src-tauri/  — Tauri v2 оболочка (десктоп)
public/campaigns/ash-of-caerden/ — демо-кампания (Campaign Package)
```

## Технологии

React + TypeScript + Vite · inkjs (Ink runtime + компилятор) · seedrandom ·
Konva/react-konva (редактор сцен) · Monaco (JSON/ink, собран в бандл — без CDN) ·
JSZip (`.chronicle`) · Tauri v2 (десктоп) · далее по ТЗ: Howler (звук, Фаза 5).

Гекс-логика и рендер боя написаны свои (odd-r/кубические координаты, A*, SVG-оверлей):
для текущего масштаба арен это проще и полностью тестируемо headless;
переход на PixiJS/honeycomb-grid предусмотрен, когда понадобятся анимации и большие карты —
боевая логика от рендера полностью отделена (`src/core/combat.ts` не знает про React/DOM).
